CHAPTER 7

Claude Code 시작하기

터미널이 무섭다고요? 괜찮아요, 같이 해봐요

해커인 줄 알았어요

얼마 전, 카페에서 옆자리에 앉은 개발자의 노트북 화면을 본 적이 있어요. 까만 화면에 알 수 없는 영어 글자들이 빠르게 지나가고, 간간이 형형색색의 텍스트가 번쩍번쩍 떴어요.

"저 사람 해킹하는 거 아냐...?"

솔직히 그렇게 생각했어요. 그런데 나중에 알고 보니, 그 사람은 그냥 터미널에서 코드를 실행하고 있었던 거예요. 파일을 만들고, 프로그램을 돌리고, 결과를 확인하는 아주 평범한 작업이었죠.

터미널은 영화에서 보는 것처럼 무서운 게 아니에요. 그냥 컴퓨터에게 글로 명령하는 창이에요. 마우스로 클릭하는 대신 키보드로 타이핑하는 것뿐이죠.

그리고 오늘 우리는 이 터미널에서 Claude를 만나볼 거예요. 바로 Claude Code를 통해서요.

Claude Code가 뭔가요?

지금까지 우리는 Claude.ai 웹사이트에서 Claude와 대화해왔어요. 질문하면 답해주고, 글을 써달라고 하면 써주고. 아주 똑똑한 대화 상대였죠.

그런데 Claude Code는 한 단계 더 나아가요. Claude.ai가 "대화만 하는 Claude"라면, Claude Code는 "직접 일하는 Claude"예요.

비유로 이해하기

Claude.ai = 전화 상담사. "이렇게 하시면 됩니다~" 하고 말로 알려줘요.
Claude Code = 출장 기사. 직접 와서 작업해줘요. 파일도 만들고, 코드도 실행하고, 결과도 보여줘요.

구체적으로 Claude Code가 하는 일을 정리하면 이래요:

  • 파일 생성과 수정: HTML, Python, 엑셀 데이터 처리 스크립트 등을 직접 만들어요
  • 코드 실행: 작성한 코드를 바로 실행하고 결과를 보여줘요
  • 프로젝트 이해: 폴더 구조를 파악하고, 기존 코드를 읽고 이해해요
  • 도구 사용: git, npm 같은 개발 도구를 직접 실행해요
  • 웹 검색: 필요한 정보를 인터넷에서 찾아와요

한마디로, Claude Code는 내 컴퓨터에서 직접 손발이 되어주는 AI 비서예요.

Claude.ai vs Claude Code: 한눈에 비교

터미널 기초: 3분이면 충분해요

Claude Code를 쓰려면 터미널을 열어야 해요. 걱정 마세요, 딱 3가지만 알면 돼요.

터미널 여는 법

  • Windows: 시작 메뉴에서 "PowerShell" 또는 "명령 프롬프트" 검색, 또는 Win + R → cmd 입력
  • Mac: Spotlight(Cmd + Space)에서 "터미널" 검색
  • VS Code 사용자: Ctrl + ` (백틱)으로 내장 터미널 열기

기본 명령어 3개

터미널에서 쓸 수 있는 수백 개의 명령어가 있지만, 지금 당장은 3개만 알면 돼요:

# 1. 지금 어디에 있는지 확인
pwd

# 2. 이 폴더에 뭐가 있는지 보기
ls

# 3. 다른 폴더로 이동하기
cd 폴더이름

이 3개만 알면 Claude Code를 시작하기에 충분해요. 나머지는 Claude Code가 알아서 해줄 거예요!

잠깐, Node.js가 필요해요!

Claude Code를 설치하려면 Node.js가 컴퓨터에 있어야 해요. Node.js는 JavaScript를 실행하는 프로그램이에요. nodejs.org에서 LTS 버전을 다운로드하고 설치하세요. 설치 후 터미널에서 node -v를 입력하면 버전이 나와요.

Claude Code 설치하기

Node.js가 준비되었으면, 설치는 명령어 한 줄이면 끝이에요:

npm install -g @anthropic-ai/claude-code

이 명령어의 의미를 풀어보면:

  • npm: Node.js의 패키지 관리자 (앱스토어 같은 거예요)
  • install: 설치해줘
  • -g: 컴퓨터 어디서든 쓸 수 있게 (global)
  • @anthropic-ai/claude-code: 이 프로그램을 설치해줘

설치가 끝나면 확인해볼까요?

claude --version

버전 번호가 나오면 성공이에요!

처음 사용해보기

이제 터미널에서 이렇게 입력해보세요:

claude

그러면 터미널 안에서 Claude와 대화하는 창이 열려요. 처음 실행하면 Anthropic 계정으로 로그인하라는 안내가 나올 거예요. 로그인하면 바로 대화를 시작합니다.

첫 번째 대화

"안녕! 이 폴더에 어떤 파일들이 있는지 알려줘."

Claude Code가 ls 명령어를 실행해서 파일 목록을 보여줄 거예요. 그런데 잠깐, 실행하기 전에 뭔가 물어볼 거예요.

안전 장치: 허락 받고 실행해요

Claude Code의 가장 중요한 특징 중 하나가 권한 시스템이에요.

Claude Code가 파일을 만들거나, 명령어를 실행하거나, 뭔가를 수정하려고 할 때는 먼저 물어봐요.

Claude wants to run: ls
Allow? (y/n)

"이거 실행해도 될까요?" 하고 허락을 구하는 거예요.

비유로 이해하기

집에 온 인테리어 기사가 벽에 못을 박기 전에 "여기 박아도 될까요?" 하고 물어보는 것과 같아요. 내가 "네"라고 해야 작업을 시작해요. 안전하죠?

매번 허락하는 게 귀찮다면, 자주 쓰는 명령어는 자동 허용으로 설정할 수도 있어요. 하지만 처음에는 하나하나 확인하면서 쓰는 걸 추천해요. Claude Code가 어떤 일을 하는지 이해하는 데 도움이 되거든요.

권한 수준 3가지

  • 읽기: 파일 내용을 읽는 건 자동으로 허용돼요
  • 쓰기: 파일을 만들거나 수정할 때 물어봐요
  • 실행: 터미널 명령어를 실행할 때 물어봐요

Claude.ai와 이렇게 달라요

핵심 차이를 다시 정리해볼게요:

시나리오: "이력서 PDF 만들어줘"

Claude.ai에서: "이력서 내용은 이렇게 구성하시면 됩니다..." 하고 텍스트로 알려줘요. 직접 워드나 한글에 붙여넣어야 하죠.

Claude Code에서: 이력서 HTML 파일을 직접 만들고, CSS로 스타일링하고, 브라우저에서 바로 열리는 완성된 파일을 만들어요.

시나리오: "이 데이터 정리해줘"

Claude.ai에서: 데이터를 채팅창에 붙여넣으면 정리된 결과를 텍스트로 보여줘요.

Claude Code에서: CSV 파일을 직접 읽고, Python 스크립트를 작성해서 실행하고, 정리된 결과를 새 파일로 저장해요.

이것이 바로 이 책의 핵심 메시지예요:

기억하세요

AI는 검색 도구가 아니라, 지시를 통한 업무 달성 도구예요. Claude Code를 쓰면 "알려줘"에서 "해줘"로 바뀌어요. 질문하는 게 아니라, 일을 시키는 거예요.

직접 해보기: 첫 Claude Code 체험

  1. Node.js가 설치되어 있는지 확인하세요: node -v
  2. Claude Code를 설치하세요: npm install -g @anthropic-ai/claude-code
  3. 아무 폴더에서 claude를 실행하세요
  4. "이 폴더에 있는 파일 목록을 보여줘"라고 말해보세요
  5. Claude Code가 어떤 명령어를 실행하려고 하는지 확인하고, 허락해주세요
  6. 결과를 확인해보세요!

어때요? Claude가 직접 컴퓨터에서 일하는 느낌이 나죠?

이번 챕터 정리

  • Claude Code는 Claude.ai의 "실행 버전"이에요. 대화만 하는 게 아니라 직접 파일을 만들고 코드를 실행해요.
  • 터미널은 무서운 게 아니에요. pwd, ls, cd 세 개만 알면 바로 시작합니다.
  • 설치는 npm install -g @anthropic-ai/claude-code 한 줄이면 끝이에요.
  • Claude Code는 중요한 작업 전에 항상 허락을 구해요. 그래서 안심하고 씁니다.
  • AI는 검색 도구가 아니라 업무 달성 도구예요.

다음 챕터 미리보기

Claude Code를 설치했으니, 이제 Claude에게 "우리 프로젝트"를 이해시켜야 해요. 새로 합류한 팀원에게 프로젝트를 설명하듯이요. 그 비밀은 CLAUDE.md라는 특별한 파일에 있어요.
