CHAPTER 12

코딩을 모르는 사람의 앱 만들기

아이디어 하나와 Claude Code가 있으면 충분해요

카페 사장님의 고민

카페를 운영하는 지은 사장님은 고민이 있었어요. 단골 고객들에게 포인트를 적립해주고 싶은데, 종이 스탬프 카드는 자꾸 잃어버리고, 기존 포인트 앱은 월 이용료가 나가고...

"간단한 포인트 앱을 하나 만들면 좋겠는데..."

개발자를 고용하면 500만 원. 외주 맡기면 3개월. 그런데 Claude Code로 하면? 추가 개발비 0원(구독료 별도), 2시간.

농담이 아니에요. 코딩을 전혀 모르는 사람이 Claude Code와 대화하면서 실제로 동작하는 웹앱을 만들 수 있어요. 이번 챕터에서 그 과정을 처음부터 끝까지 같이 걸어볼게요.

기억하세요

AI는 검색 도구가 아니라 지시를 통한 업무 달성 도구예요. "앱 만드는 법 알려줘"가 아니라 "이런 앱 만들어줘"라고 지시하는 거예요.

Step 1: 아이디어 정리하기

첫 번째 단계는 코딩이 아니에요. 내가 원하는 걸 말로 설명하는 것이에요.

Claude Code를 열고, 이렇게 말해보세요:

이렇게 하지 마세요

"앱 만들어줘"

이렇게 하세요

"카페 단골 고객 포인트 앱을 만들고 싶어. 고객이 전화번호로 로그인하면 포인트 조회/적립이 되고, 사장님은 관리자 화면에서 포인트를 부여할 수 있어. 웹 브라우저에서 작동하면 좋겠어. 디자인은 따뜻한 카페 느낌으로."

구체적일수록 좋아요. Claude는 내 마음을 읽는 독심술사가 아니에요. 하지만 너무 걱정하지 마세요. 처음부터 완벽할 필요 없어요. Claude가 질문을 해올 거예요.

Claude의 반응 예시

"좋은 아이디어네요! 몇 가지 질문이 있어요:
1. 포인트는 금액 기준인가요, 방문 횟수 기준인가요?
2. 포인트로 교환할 수 있는 보상이 있나요?
3. 데이터는 어디에 저장할까요? (로컬 vs 서버)
4. 동시에 몇 명 정도 사용할 예정인가요?"

이런 질문에 답하면서 아이디어가 구체화돼요!

Step 2: 기술 스택 제안 받기

"기술 스택"이라는 말이 어렵게 들리죠? 그냥 "어떤 도구로 만들까?"예요.

Claude에게 이렇게 물어보세요:

이렇게 하세요

"나는 코딩을 전혀 모르는 사람이야. 이 앱을 가장 간단하게 만들 수 있는 방법을 제안해줘. 무료로 배포할 수 있으면 좋겠어."

Claude가 알아서 내 수준에 맞춰 제안해줄 거예요. 비개발자에게는 보통 이렇게 제안해요:

  • HTML + CSS + JavaScript: 가장 기본이 되는 웹 기술. 별도 설치 없이 브라우저에서 바로 실행돼요
  • 데이터 저장: 간단하면 localStorage(브라우저 저장), 복잡하면 Firebase 같은 무료 서비스
  • 배포: GitHub Pages나 Vercel로 무료 배포

이 기술들을 이해할 필요는 없어요. Claude가 다 처리해줘요. "좋아, 그렇게 해줘"라고만 하면 돼요.

Step 3: 한 번에 하나씩 구현 시키기

여기가 가장 중요한 부분이에요. 절대로 전체를 한 번에 시키지 마세요.

이렇게 하지 마세요

"로그인, 포인트 적립, 관리자 화면, 보상 교환, 통계 대시보드 다 만들어줘"

이렇게 하세요

"먼저 기본 HTML 페이지를 만들어줘. 카페 로고 자리, 전화번호 입력 칸, 로그인 버튼만 있으면 돼."

그 다음, 하나씩 추가해가요:

  1. "로그인 기능이 동작하게 해줘. 전화번호를 입력하면 포인트 화면으로 넘어가게."
  2. "포인트 조회 화면을 만들어줘. 현재 포인트와 최근 적립 내역이 보이게."
  3. "사장님 전용 관리자 페이지를 추가해줘. 관리자 비밀번호는 .env 파일의 환경 변수에서 읽도록 해줘."
  4. "관리자 페이지에서 고객 전화번호를 입력하면 포인트를 추가할 수 있게."

이렇게 한 단계씩 진행하면, 중간에 문제가 생겨도 어디서 잘못됐는지 쉽게 찾을 수 있어요.

비개발자를 위한 핵심 팁

"작동하는 걸 먼저, 예쁜 건 나중에." 기능이 돌아가는 걸 확인한 후에 디자인을 다듬으세요. 처음부터 예쁘게 만들려고 하면 둘 다 잃어요.

Step 4: 수정 요청하기

만들어진 앱을 브라우저에서 열어보세요. 마음에 안 드는 부분이 있을 거예요. 그게 정상이에요!

수정 요청은 일상 언어로 하면 돼요:

  • "버튼 색을 갈색에서 연한 초록색으로 바꿔줘"
  • "글씨가 너무 작아. 좀 더 크게 해줘"
  • "포인트 숫자 옆에 커피 아이콘을 넣어줘"
  • "메뉴에 '이벤트' 탭을 추가해줘"
  • "모바일에서 보면 레이아웃이 깨지는데 고쳐줘"

전문 용어를 몰라도 괜찮아요. "그 위에 있는 거 왼쪽으로 옮겨줘" 같은 표현도 Claude는 이해해요.

에러가 났을 때

에러 메시지가 나오면 당황하지 마세요. 그냥 에러 메시지를 그대로 복사해서 Claude에게 보여주세요.

"이런 에러가 나는데 고쳐줘: TypeError: Cannot read properties of undefined (reading 'points')"

에러를 이해할 필요 없어요. Claude가 읽고 고쳐줘요. 마치 자동차 엔진에서 이상한 소리가 나면 정비사에게 "이런 소리가 나요"라고 하는 것처럼요.

Step 5: 세상에 공개하기 (배포)

앱이 완성됐으면, 다른 사람들도 쓸 수 있게 인터넷에 올려야 해요. 이걸 "배포"라고 해요.

Claude에게 이렇게 말하면 돼요:

이렇게 하세요

"이 앱을 인터넷에서 누구나 접속할 수 있게 배포하고 싶어. 무료로 할 수 있는 가장 쉬운 방법 알려줘. 단계별로 안내해줘."

무료 배포 옵션:

  • GitHub Pages: 정적 웹사이트에 적합. 완전 무료
  • Vercel: 좀 더 복잡한 앱도 가능. 개인 프로젝트 무료
  • Netlify: Vercel과 비슷. 쉬운 인터페이스

Claude가 배포 과정도 단계별로 안내해줄 거예요. 따라 하기만 하면 돼요.

완전한 앱 개발 플로우

  1. 아이디어 정리: 만들고 싶은 앱을 구체적으로 설명 (10분)
  2. Claude와 대화: 기술 스택, 구조 논의 (10분)
  3. 기본 틀 생성: 첫 번째 화면 만들기 (15분)
  4. 기능 추가: 한 번에 하나씩, 대화하며 추가 (30-60분)
  5. 디자인 다듬기: 색상, 폰트, 레이아웃 조정 (15분)
  6. 테스트: 직접 써보고 문제 발견 → 수정 요청 (15분)
  7. 배포: 인터넷에 공개 (10분)

총 소요 시간: 약 2시간

비개발자를 위한 생존 팁

팁 1: 전체를 한 번에 시키지 말고 단계별로

큰 요청을 하면 Claude도 헷갈려해요. "먼저 이것만 해줘" → "잘 됐어, 그 다음 이것" → 이 리듬이 가장 좋아요.

팁 2: 에러 메시지는 그대로 보여주세요

"안 돼요"라고만 하면 Claude도 뭐가 문제인지 몰라요. 에러 메시지를 복사 붙여넣기 하세요. 스크린샷도 좋아요.

팁 3: 완벽하지 않아도 돼요

첫 버전이 완벽할 필요 없어요. 만들고 → 써보고 → 고치고. 이 반복이 소프트웨어 개발의 본질이에요. 전문 개발자들도 이렇게 해요.

팁 4: 자주 저장하세요

Claude에게 "지금까지 만든 거 잘 되니까, 여기서 git commit 해줘"라고 말해보세요. 문제가 생기면 이전 상태로 돌아갈 수 있어요. 게임의 세이브 포인트와 같은 거예요.

실습: 5분 만에 자기소개 웹페이지 만들기

지금 바로 해볼 수 있는 간단한 실습이에요:

  1. 터미널에서 Claude Code를 실행하세요
  2. 이렇게 말하세요: "나만의 자기소개 웹페이지를 만들어줘. 이름은 [내 이름], 취미는 [취미], 좋아하는 말은 [명언]. 깔끔하고 예쁜 디자인으로. 한 페이지짜리 HTML로 만들어줘."
  3. 생성된 HTML 파일을 브라우저에서 열어보세요
  4. 마음에 안 드는 부분을 Claude에게 수정 요청하세요
  5. 3번 이상 수정을 반복해보세요. 점점 마음에 드는 페이지가 될 거예요!

축하해요! 방금 "개발"을 한 거예요. 코드를 한 줄도 직접 쓰지 않았지만요.

잠깐, 정리!

  • 코딩을 몰라도 Claude Code와 대화하면서 실제 동작하는 앱을 만들 수 있어요
  • 핵심은 구체적인 설명과 단계별 진행이에요
  • 에러가 나면 에러 메시지를 그대로 복사해서 Claude에게 보여주세요
  • 완벽하지 않아도 돼요. 만들고, 써보고, 고치는 반복이 핵심이에요
  • GitHub Pages나 Vercel로 무료 배포까지 가능해요
