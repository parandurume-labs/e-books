CHAPTER 2

Claude를 만나다

세 가지 Claude, 어디서 만나면 좋을까?

Claude라는 이름은 들어봤는데, 정확히 뭔지 모르겠다고요? 걱정 마세요. 카카오톡도 처음엔 "그게 뭔데?"였잖아요. 스마트폰 나왔을 때도 "전화기에 터치가 왜 필요해?"라고 했던 사람들이 지금은 하루 종일 스마트폰을 놓질 못하죠.

Claude도 마찬가지예요. 한번 제대로 써보면, "이거 없이 어떻게 일했지?"라는 말이 자연스럽게 나올 거예요.

Claude란?

Claude는 Anthropic이라는 AI 안전 연구 회사가 만든 AI 어시스턴트예요. "그냥 또 하나의 챗봇 아냐?"라고 생각할 수도 있는데, Claude는 좀 특별해요.

  • 긴 문서도 한 번에 이해해요: 200페이지짜리 계약서? 통째로 읽고 분석해요
  • 정직하려고 노력해요: 모르는 건 모른다고 말하는 AI예요
  • 맥락을 잘 기억해요: 대화가 길어져도 앞에서 말한 걸 잊지 않아요
  • 한국어를 잘해요: 자연스러운 한국어로 써요

하지만 Claude의 진짜 매력은 하나가 아니라 세 가지 형태로 만난다는 점이에요. 마치 같은 배우가 영화, 드라마, 연극에서 각각 다른 매력을 보여주듯이요.

세 가지 Claude

1. Claude.ai: 브라우저에서 바로 대화

가장 접근하기 쉬운 형태예요. 웹 브라우저에서 claude.ai에 접속하면 바로 대화를 시작해요. 모바일 앱도 있고요.

  • 사용 환경: 웹 브라우저, iOS/Android 앱
  • 대상: 모든 사용자 (직장인, 학생, 누구나)
  • 핵심 기능: 대화, 문서 작성, 파일 분석, Projects, Artifacts
  • 추천 용도: 이메일 작성, 보고서 초안, 데이터 분석, 번역, 브레인스토밍

2. Claude Desktop: 내 컴퓨터와 연결

Mac이나 Windows에 설치하는 데스크톱 앱이에요. 겉보기에는 Claude.ai와 비슷하지만, 결정적인 차이가 있어요. MCP(Model Context Protocol)로 내 컴퓨터의 파일, 데이터베이스, 외부 서비스와 직접 연결한다는 점이죠.

  • 사용 환경: Mac/Windows 데스크톱 앱
  • 대상: 로컬 파일 작업이 필요한 사용자
  • 핵심 기능: Claude.ai 기능 + MCP 서버 연결
  • 추천 용도: 로컬 파일 분석, DB 조회, GitHub 연동, Slack 자동화

3. Claude Code: 터미널의 강력한 동반자

터미널(명령줄)에서 실행하는 Claude예요. 가장 강력한 형태죠. 코딩만을 위한 게 아니에요. 파일을 만들고, 프로젝트를 구조화하고, 시스템을 관리하고, 복잡한 자동화까지 해요.

  • 사용 환경: 터미널 / CLI
  • 대상: 개발자, 파워 유저
  • 핵심 기능: 코딩, 파일 생성/편집, 프로젝트 관리, Git 연동, 시스템 관리
  • 추천 용도: 소프트웨어 개발, 스크립트 자동화, 프로젝트 구축

언제 뭘 쓰면 될까?

상황에 따라 가장 적합한 Claude를 골라보세요.

사무직 김대리: "보고서 초안을 빨리 써야 해요. 참고 자료 PDF도 있고요."
→ Claude.ai: PDF 업로드하고, 보고서를 시키세요. Projects에 자료를 모아두면 더 편해요.

대학생 이서연: "논문 자료 정리하고 발표 스크립트 써야 해요."
→ Claude.ai: 논문 PDF를 올려서 요약시키고, 발표 스크립트까지 한 번에 시키세요.

프리랜서 박디자이너: "로컬 폴더의 프로젝트 파일을 정리하고 싶어요."
→ Claude Desktop + Filesystem MCP: 로컬 파일에 직접 접근해서 정리, 분류, 이름 변경까지.

개발자 최시니어: "새 프로젝트 구조를 세팅하고 코드를 짜야 해요."
→ Claude Code: 터미널에서 프로젝트 생성부터 코딩까지 한 번에.

실무 워크플로: 오늘의 업무에 맞는 Claude 고르기

  1. 웹에서 간단히 대화하면서 작업? → Claude.ai로 가세요
  2. 내 컴퓨터 파일을 AI가 직접 다뤄야 해? → Claude Desktop 설치하세요
  3. 코드를 짜거나 프로젝트를 관리해야 해? → Claude Code를 여세요
  4. 잘 모르겠어? → Claude.ai부터 시작하세요. 거기서 90%는 해결돼요!

Anthropic 공식 학습 리소스

Claude를 더 깊이 배우고 싶다면, Anthropic이 직접 제공하는 자료들이 있어요.

  • platform.claude.com/docs: API 공식 문서. 사용법부터 모델 특성까지 상세하게 나와 있어요 (2026년 7월 기준 주소예요)
  • code.claude.com/docs: Claude Code 공식 문서. 설치부터 설정까지 여기서 봐요 (2026년 7월 기준 주소예요)
  • Anthropic Cookbook: 실전 예제 모음. 실제 코드와 함께 다양한 활용 사례를 보여줘요
  • Prompt Engineering Guide: 프롬프트를 잘 쓰는 공식 가이드. 다음 챕터에서 배울 내용의 원본이에요
  • Claude 모델 카드: 각 모델(Haiku, Sonnet, Opus)의 특성과 차이점

무료 vs 유료

Claude.ai는 무료로 시작합니다! 무료 플랜으로도 충분히 많은 걸 할 수 있고, 더 많이 쓰게 되면 Pro(2026년 7월 기준 $20/월)로 업그레이드하면 돼요. Pro보다 한도가 큰 Max 티어도 있어요. Claude Code는 Pro나 Max 같은 유료 플랜, 또는 API 키가 필요해요.

실습: Claude에게 첫 인사하기

  1. Claude.ai에 접속하세요: claude.ai에서 무료 계정 만들기
  2. 자기소개를 시켜보세요: "너 자신을 소개해줘. 어떤 일을 잘하는지, 어떤 한계가 있는지 솔직하게"
  3. 간단한 업무를 시켜보세요. 예: "내일 팀 회의에서 쓸 5분 분량의 프로젝트 진행 상황 발표 스크립트 써줘. 프로젝트는 사내 인트라넷 리뉴얼이고, 진행률 70%, 남은 이슈는 로그인 UI 개선이야."
  4. 결과를 수정해 보세요: "좀 더 캐주얼하게 바꿔줘" 또는 "불릿 포인트로 정리해줘"

이 네 단계만 해봐도, AI를 "검색"이 아닌 "지시"로 쓰는 감각이 잡힐 거예요.

잠깐, 정리!

  • Claude는 Anthropic이 만든 AI 어시스턴트
  • Claude.ai: 웹/앱에서 바로 사용. 가장 접근하기 쉬움
  • Claude Desktop: 로컬 파일 접근 + MCP 확장
  • Claude Code: 터미널에서 코딩과 프로젝트 관리. 가장 강력
  • 잘 모르겠으면 Claude.ai부터 시작하면 된다
  • Anthropic 공식 문서에서 더 깊이 배운다
