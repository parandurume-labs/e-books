CHAPTER 15

Claude 생태계 탐험

Claude의 세계는 생각보다 넓어요

지도를 펼쳐봅시다

지금까지 Claude.ai, Claude Desktop, Claude Code를 배웠어요. 하지만 이건 빙산의 일각이에요. Claude 주변에는 공식 문서, 학습 자료, API, 커뮤니티 등 방대한 생태계가 있어요.

이번 챕터에서는 더 깊이 배우고 더 멋진 걸 만들도록 생태계 전체를 안내할게요. 일종의 관광 가이드라고 생각하세요!

Anthropic 공식 리소스

platform.claude.com/docs: API 공식 문서

모든 것의 시작점이에요. Claude API 사용법, 모델 정보, 모범 사례가 정리되어 있어요. 영어가 기본이지만, 번역 도구와 함께 사용하면 충분히 이해할 수 있어요 (2026년 7월 확인).

Anthropic Cookbook: 실전 레시피

github.com/anthropics/anthropic-cookbook에 있어요. "레시피"라는 이름처럼, 실제로 따라 할 수 있는 예제 코드 모음이에요.

Cookbook에서 찾을 수 있는 것들

- PDF 문서 분석하기
- 이미지 이해하고 설명하기
- 긴 문서 요약하기
- 구조화된 데이터(JSON) 추출하기
- 프롬프트 캐싱으로 비용 절약하기
- 도구 사용(Tool Use)으로 외부 시스템 연동하기

각 레시피는 코드와 설명이 함께 있어서, 복사-붙여넣기로 바로 테스트해볼 수 있어요.

code.claude.com/docs: Claude Code 공식 문서

Claude Code의 모든 기능, 설정, 슬래시 명령어가 정리되어 있어요. 이 책에서 다룬 것보다 더 자세한 내용이 있으니, 궁금한 기능이 있으면 찾아보세요 (2026년 7월 확인).

Prompt Engineering Interactive Tutorial

Anthropic이 만든 프롬프트 엔지니어링 튜토리얼이에요. 단순히 읽는 게 아니라 직접 해보면서 배우는 인터랙티브 형식이에요. 프롬프트 실력을 한 단계 올리고 싶다면 꼭 해보세요.

Claude API: 개발자를 위한 직접 연동

Claude.ai는 웹 브라우저에서 대화하는 거예요. Claude Code는 터미널에서 쓰는 거예요. 그렇다면 내가 만든 앱에 Claude를 넣고 싶으면 어떻게 할까요?

바로 API를 사용하면 돼요. API는 "프로그램이 Claude와 대화하는 방법"이에요.

예를 들어, 고객 지원 챗봇을 만든다고 해보세요. 내 웹사이트에 채팅 창을 넣고, 고객이 질문을 입력하면 Claude API로 답변을 받아서 보여주는 거예요. 이 모든 게 자동으로 돌아가요.

API 시작하기 (간략)

  1. API 키 발급: console.anthropic.com에서 회원가입 후 API 키를 받아요
  2. SDK 설치: Python이면 pip install anthropic, JavaScript면 npm install @anthropic-ai/sdk
  3. 코드 작성: 몇 줄이면 Claude와 대화할 수 있어요

Python으로 Claude API 호출 (간단 예시)

import anthropic
client = anthropic.Anthropic()
message = client.messages.create(
  model="여기에 최신 모델 ID",
  max_tokens=1024,
  messages=[{"role": "user", "content": "안녕하세요!"}]
)
print(message.content[0].text)

모델 ID는 자주 바뀌니까 여기에 적지 않을게요. platform.claude.com/docs의 모델 목록에서 최신 모델 ID를 확인해서 쓰세요.

이 몇 줄로 Claude가 내 프로그램 안에서 동작해요. 마법 같죠?

Agent SDK: 나만의 에이전트 만들기

API보다 한 단계 더 나아가면, Agent SDK가 있어요. 이건 Claude를 단순히 "질문-답변" 도구가 아니라, 스스로 계획하고 실행하는 에이전트로 만들어줘요.

Agent SDK로 할 수 있는 것들:

  • 고객 문의를 자동으로 분류하고 답변하는 에이전트
  • 데이터를 분석하고 보고서를 자동 생성하는 에이전트
  • 코드를 자동으로 리뷰하고 PR을 올리는 에이전트
  • 정기적으로 웹사이트를 모니터링하고 알림을 보내는 에이전트

API vs Agent SDK

API: "이 질문에 답해줘" → 답변 받기. 단발성 대화.
Agent SDK: "이 목표를 달성해줘" → 스스로 계획을 세우고, 도구를 사용하며, 여러 단계를 거쳐 목표 달성. 자율적 실행.

한국어 AI 커뮤니티도 점점 활발해지고 있어요. AI 관련 카카오톡 오픈채팅방, 네이버 카페, 그리고 다양한 테크 커뮤니티에서 Claude 사용 경험을 나눠요.

역할별 학습 경로

어디서부터 시작해야 할지 모르겠다면, 내 역할에 맞는 경로를 따라가세요:

사무직 (비개발자)

  1. Claude.ai에서 기본 대화 연습
  2. Projects로 업무별 맥락 관리
  3. Claude Desktop으로 내 컴퓨터 파일과 연결
  4. Prompt Engineering Tutorial로 프롬프트 실력 향상
  5. 업무별 프롬프트 템플릿 (부록 B) 활용

개발자

  1. Claude Code 설치 및 기본 사용
  2. Skills로 자주 하는 작업 자동화
  3. MCP로 개발 도구 연동 (GitHub, DB 등)
  4. API / SDK로 내 프로젝트에 Claude 통합
  5. Anthropic Cookbook으로 고급 패턴 학습

창업자 / 1인 개발자

  1. Claude Code로 빠르게 프로토타입 개발
  2. gstack으로 전체 프로젝트 관리
  3. 멀티 에이전트로 동시에 여러 작업 처리
  4. Agent SDK로 자동화된 워크플로 구축
  5. 비즈니스 로직에 Claude API 직접 통합

실습: Anthropic Cookbook 탐험하기

  1. github.com/anthropics/anthropic-cookbook에 접속하세요
  2. README를 읽고, 어떤 레시피들이 있는지 살펴보세요
  3. 관심 있는 레시피를 하나 골라보세요 (추천: "Prompt Caching" 또는 "PDF support")
  4. 해당 레시피의 코드를 Claude Code에게 보여주고, "이 예제를 따라 해볼 수 있게 도와줘"라고 말해보세요
  5. 직접 실행해보고, 결과를 확인하세요!

Cookbook의 레시피를 하나 따라해보면, "아, 이런 것도 가능하구나!"하는 새로운 가능성을 발견하게 될 거예요.
