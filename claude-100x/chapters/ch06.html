CHAPTER 6

실무 시나리오: 사무직의 하루

아침 9시부터 저녁 6시까지, Claude와 함께

이론은 충분히 배웠어요. 이제 실전이에요. 김대리의 하루를 따라가 봅시다. 3년차 사무직, 중견 제조업체 마케팅팀 소속. 월요일 아침 9시, 출근해서 컴퓨터를 켭니다. 오늘도 할 일이 산더미예요.

하지만 김대리에겐 비밀 무기가 있어요. Claude입니다.

09:00 — 이메일 작성 (Claude.ai)

출근하자마자 팀장님이 말합니다. "김대리, 신한제약 김 부장님께 다음 주 미팅 확인 이메일 보내. 아, 이번에 좀 정중하게 보내."

상황: 거래처 담당자에게 미팅 확인 이메일을 보내야 함. 정중하지만 자연스러운 톤이 필요.

예전 김대리라면 "비즈니스 이메일 쓰는 법"을 검색했을 거예요. 하지만 이제는 다릅니다.

김대리의 프롬프트

"신한제약 마케팅팀 김영수 부장님께 보낼 이메일을 써줘.

내용: 다음 주 수요일 오후 2시, 우리 본사 3층 회의실에서 진행 예정인 Q2 공동 마케팅 협업 미팅 일정 확인.

톤: 비즈니스 격식체, 하지만 딱딱하지 않고 따뜻하게. 한국 비즈니스 문화에 맞게.

포함할 내용: 미팅 안건 간략 언급, 주차 안내, 준비 사항이 있으면 말씀해 달라는 문구."

소요 시간: 2분. 예전에는 15분 걸리던 일이에요. 결과물을 한 번 읽어보고, "조금 더 간결하게 줄여줘"라고 한마디 하면 끝.

10:00 — 회의록 정리 (Claude.ai + 파일 업로드)

10시, 주간 팀 미팅이 끝났습니다. 김대리는 미팅 중에 휴대폰으로 메모를 해뒀어요. 두서없는 메모지만 괜찮아요.

상황: 30분간의 팀 미팅 후, 두서없는 메모를 구조화된 회의록으로 정리해야 함.

김대리의 프롬프트

"아래 미팅 메모를 공식 회의록으로 정리해줘.

형식: 1) 회의 정보 (일시, 참석자, 장소) 2) 핵심 논의 사항 3) 결정 사항 4) 액션 아이템 (담당자, 마감일 포함) 5) 다음 미팅 일정

[여기에 메모 붙여넣기]
- 팀장님이 Q2 예산 10% 증가 가능하다고 함
- SNS 광고 효율 떨어져서 인플루언서 마케팅으로 전환 검토
- 이주임이 인플루언서 리스트 이번 주 금요일까지 만들기로
- 신제품 런칭 일정 4월 15일에서 4월 22일로 연기
- 박과장이 경쟁사 SNS 분석 자료 만들어오기로 (수요일까지)
- 다음 미팅은 다음 주 월요일 같은 시간"

소요 시간: 3분. 깔끔한 회의록이 나오고, 액션 아이템에 담당자와 마감일까지 정리되어 있어요. 예전에는 이거 하나에 20분은 걸렸는데요.

11:00 — 보고서 초안 작성 (Projects)

11시, 팀장님이 "이번 주 금요일까지 Q1 마케팅 실적 보고서 올려"라고 합니다. 김대리는 미리 만들어둔 "마케팅 보고서" Project를 엽니다.

상황: Q1 마케팅 실적 보고서를 경영진 대상으로 작성해야 함. 이미 Project에 지난 분기 보고서, KPI 기준표, 채널별 데이터가 업로드되어 있음.

Project 안에서의 프롬프트 (맥락 설명 불필요!)

"Q1 마케팅 실적 보고서 초안 써줘. 아래 데이터를 기반으로.

[Q1 채널별 성과 데이터 붙여넣기]
- 네이버 블로그: 월평균 방문 12만, 전분기 대비 +15%
- 인스타그램: 팔로워 8.5만, 전분기 대비 +22%
- 유튜브: 구독자 3.2만, 조회수 평균 2만회/영상
- 온라인 매출: 전분기 대비 +18%

경영진 대상이니까 핵심 성과 3줄 요약을 먼저 넣어줘."

Project의 Custom Instructions에 이미 "격식체, 표 활용, 숫자 근거 포함"이 설정되어 있어서, 이런 세부 지시 없이도 원하는 스타일로 나와요.

소요 시간: 15분 (초안 + 2번 수정). 예전에는 3시간 넘게 걸리던 일이에요.

14:00 — 데이터 분석 (Claude Desktop + MCP)

점심 먹고 돌아오니, 팀장님이 또 한마디 합니다. "김대리, 바탕화면에 있는 고객 설문조사 데이터 좀 분석해봐."

상황: 바탕화면에 '고객설문_2025Q1.csv' 파일이 있음. 500명의 설문 응답 데이터. Claude Desktop에 Filesystem MCP가 연결되어 있음.

Claude Desktop에서의 프롬프트

"바탕화면의 '고객설문_2025Q1.csv' 파일을 읽어서 분석해줘.

분석 항목:
1. 전체 만족도 평균 및 분포
2. 연령대별 만족도 차이
3. 가장 많이 언급된 불만 사항 TOP 5
4. NPS(Net Promoter Score) 계산
5. 개선 우선순위 추천 3가지

결과를 마크다운 표로 정리하고, 분석 결과를 '설문분석_결과.md'로 바탕화면에 저장해줘."

Claude Desktop이 직접 파일을 읽고, 분석하고, 결과 파일까지 저장해 줘요. 파일 업로드도, 다운로드도 필요 없어요.

소요 시간: 5분. 엑셀에서 피벗 테이블 만들고 차트 그리던 것보다 훨씬 빠르죠.

15:30 — 번역 및 교정 (Claude.ai)

오후 3시 반, 해외 거래처에서 영문 이메일이 왔어요. 내용이 꽤 길고, 기술적인 용어도 있어요.

상황: 영문 이메일 번역 + 한국어 답장 초안 작성이 필요.

김대리의 프롬프트

"아래 영문 이메일을 자연스러운 한국어로 번역해줘. 기술 용어는 한글(영문 병기) 형태로.

[영문 이메일 붙여넣기]

그리고 이 이메일에 대한 답장 초안도 한국어로 써줘. 톤은 정중하되 긍정적으로. 핵심 메시지는 '일정 조율이 필요하지만 협업 의지가 있다'."

한 번의 프롬프트로 번역 + 답장까지 완료. "이 부분은 좀 더 부드럽게"라고 한마디 하면 톤 조절도 바로 돼요.

소요 시간: 3분.

17:00 — 내일 준비 (Claude.ai)

퇴근 30분 전. 김대리는 오늘 하루를 마무리합니다.

하루 마무리 프롬프트

"오늘 내가 한 업무를 정리해줘. 아래 내용 기반으로:

- 신한제약 미팅 확인 이메일 발송 완료
- 주간 미팅 회의록 작성 및 공유
- Q1 마케팅 실적 보고서 초안 완료 (금요일까지 최종본 제출 예정)
- 고객 설문조사 데이터 분석 완료
- 해외 거래처 이메일 번역 및 답장 발송

그리고 내일 해야 할 일 리스트도 만들어줘:
- 보고서 최종 수정
- 인플루언서 리스트 이주임에게 요청 확인
- 신제품 런칭 연기 관련 일정 업데이트
- 경쟁사 SNS 분석 자료 박과장에게 요청

오늘 업무 일지 형식과 내일 할 일을 체크리스트 형식으로 정리해줘."

소요 시간: 2분.

하루 절약 시간 계산

김대리의 하루를 정리해 볼게요.

물론 이건 이상적인 시나리오예요. 실제로는 AI의 결과물을 검토하고 수정하는 시간이 좀 더 들겠죠. 하지만 보수적으로 잡아도 하루 2~3시간은 확실히 절약할 수 있어요.

그 시간에 뭘 할 수 있을까요?

  • 전략적 사고에 집중하기
  • 팀원들과 소통하기
  • 새로운 아이디어 구상하기
  • 또는... 칼퇴하기!

쉬운 비유

세탁기가 나오기 전에는 빨래하는 데 반나절이 걸렸어요. 세탁기가 나온 후에는? 빨래를 넣고 버튼만 누르면 돼요. Claude는 사무직의 세탁기예요. 반복적이고 시간 많이 드는 업무를 자동화해서, 여러분이 정말 중요한 일에 집중할 수 있게 해줘요.

실습: 내일 업무 3가지를 Claude에게 시키기

  1. 내일 할 업무 리스트를 적어보세요 (최소 5개)
  2. 그중 AI에게 시킬 수 있는 3가지를 골라보세요
    • 이메일/문서 작성?
    • 데이터 정리/분석?
    • 번역/교정?
    • 아이디어 브레인스토밍?
    • 일정/계획 수립?
  3. 각 업무에 대해 4원칙을 적용한 프롬프트를 미리 작성해 두세요
  4. 내일 출근해서 실제로 실행하세요!

한 번 해보면 "아, 이래서 AI를 '시키기' 모드로 쓰라고 한 거구나"를 몸으로 느끼게 될 거예요.

잠깐, 정리!

  • 이메일 → Claude.ai에 구체적으로 시키면 2분 컷
  • 회의록 → 메모만 던져도 구조화된 회의록 완성
  • 보고서 → Projects에 맥락 저장해두면 초안 15분
  • 데이터 분석 → Claude Desktop + MCP로 파일 직접 분석
  • 번역 → 번역 + 답장을 한 번에
  • 하루 절약 시간: 보수적으로 2~3시간
  • 핵심: AI는 검색 도구가 아니라 업무 달성 도구

사무직뿐 아니라 개발자를 위한 강력한 도구, Claude Code를 만나볼 거예요. 터미널에서 코딩은 물론이고 프로젝트 생성, Git 관리, 자동화까지 — Claude의 진짜 파워를 경험하게 될 거예요!
