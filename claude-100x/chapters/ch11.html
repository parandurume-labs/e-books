CHAPTER 11

MCP 서버: Claude의 능력을 확장하다

Claude에게 새로운 초능력을 부여하세요

똑똑하지만 손발이 묶인 AI

Claude는 정말 똑똑해요. 글도 잘 쓰고, 코드도 잘 짜고, 분석도 잘 해요.

그런데 혼자서는 못 하는 것들이 있어요:

  • "이 내용으로 팀 Teams 채널에 메시지 보내줘" → Teams에 접근할 수가 없어요
  • "우리 DB에서 이번 달 매출 뽑아줘" → 데이터베이스에 연결할 수가 없어요
  • "GitHub에 이슈 등록해줘" → GitHub API를 직접 호출할 수가 없어요

Claude의 머리는 좋은데, 손발이 묶여 있는 거예요.

MCP 서버가 바로 그 손발을 풀어주는 역할을 해요. Claude와 외부 서비스 사이에 다리를 놓아주는 거죠.

MCP란 뭔가요?

MCP는 Model Context Protocol의 약자예요. 쉽게 말하면, AI가 외부 서비스와 소통하기 위한 표준 규격이에요.

USB 허브를 생각해보세요

노트북에 USB 포트가 하나 있어요. 여기에 USB 허브를 꽂으면? 마우스, 키보드, 외장하드, 프린터... 다양한 장치를 연결할 수 있게 되죠. MCP는 Claude의 USB 허브예요. MCP를 통해 Microsoft Teams, GitHub, 데이터베이스, 파일 시스템 등 다양한 서비스를 연결할 수 있어요.

중요한 건, MCP가 표준이라는 거예요. USB 케이블이 어떤 장치든 연결할 수 있듯이, MCP 프로토콜을 따르는 서버라면 어떤 서비스든 Claude에 연결할 수 있어요.

어디서 MCP를 설정하나요?

MCP 서버는 Claude Code와 Claude Desktop 모두에서 사용할 수 있지만, 설정 방법이 조금 달라요:

Claude Code에서

프로젝트의 .claude/settings.json 파일에서 설정해요:

// .claude/settings.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/folder"]
    }
  }
}

Claude Desktop에서

claude_desktop_config.json 파일에서 설정해요:

// claude_desktop_config.json (Claude Desktop)
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/folder"]
    }
  }
}

구조는 거의 같아요. 파일 위치만 다를 뿐이죠.

인기 MCP 서버들과 실무 활용

이미 수많은 MCP 서버가 만들어져 있어요. 대표적인 것들을 살펴볼까요?

1. Filesystem — 로컬 파일 관리

컴퓨터의 파일을 읽고, 쓰고, 정리할 수 있어요.

실무 활용: 대량 파일 이름 변경

"Downloads 폴더에 있는 사진 파일들을 날짜별로 이름 변경하고 정리해줘"

수백 개의 파일을 일일이 이름 바꾸는 대신, Claude에게 시키면 몇 초 만에 끝나요.

2. GitHub — 이슈/PR 관리

GitHub의 이슈를 만들고, PR을 관리하고, 코드를 검토할 수 있어요.

실무 활용: 이슈 자동 생성

"이번 스프린트에서 해야 할 작업 5개를 GitHub 이슈로 등록해줘. 각 이슈에 라벨과 마일스톤도 붙여줘."

3. Microsoft Teams — 메시지 보내기

Teams 채널에 메시지를 보내거나, 채널의 대화를 읽을 수 있어요. Slack이나 Discord를 쓰는 팀은 해당 MCP 서버로 그대로 바꿔 쓰면 됩니다.

실무 활용: 일일 보고 자동 전송

"오늘 커밋한 내용을 정리해서 #daily-standup 채널에 보고 메시지로 보내줘"

4. Database — DB 조회

데이터베이스에 연결해서 쿼리를 실행하고 결과를 분석할 수 있어요.

실무 활용: 매출 데이터 분석

"이번 달 매출 데이터를 조회하고, 전월 대비 성장률과 Top 10 상품을 정리해줘"

5. Browser — 웹 크롤링

웹 페이지를 방문하고, 내용을 읽고, 스크린샷을 찍을 수 있어요.

실무 활용: 경쟁사 가격 모니터링

"경쟁사 3곳의 주요 상품 가격을 확인하고, 우리 가격과 비교 표를 만들어줘"

6. Cloudflare — 배포 관리

Cloudflare Workers, D1 데이터베이스, R2 스토리지 등을 관리할 수 있어요.

MCP 서버 설정하기 — 단계별 가이드

Filesystem MCP 서버를 예시로 설정해볼게요:

Step by Step: Filesystem MCP 연결하기

  1. 프로젝트에 .claude 폴더 만들기 
    mkdir -p .claude
  2. settings.json 파일 만들기 
    // .claude/settings.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/me/Documents"
      ]
    }
  }
}

    /Users/me/Documents 부분을 여러분의 폴더 경로로 바꾸세요.

  3. Claude Code 실행 
    claude

    Claude Code가 시작하면서 MCP 서버를 자동으로 연결해요.

  4. 테스트

    "Documents 폴더에 있는 파일 목록을 보여줘"라고 말해보세요.

여러 MCP 서버 동시에 사용하기

mcpServers 안에 여러 서버를 추가할 수 있어요:

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/docs"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_your_token_here"
      }
    }
  }
}

이렇게 하면 Claude가 파일 시스템도 접근하고, GitHub도 접근할 수 있게 돼요. USB 허브에 장치를 여러 개 꽂는 것처럼요!

나만의 MCP 서버 만들기 (맛보기)

기존 MCP 서버에 원하는 기능이 없다면? 직접 만들 수도 있어요!

Anthropic에서 제공하는 MCP SDK를 사용하면 돼요:

# TypeScript MCP SDK 설치
npm install @modelcontextprotocol/sdk

간단한 예시 — 현재 날씨를 알려주는 MCP 서버:

import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

const server = new McpServer({
  name: "weather",
  version: "1.0.0"
});

// 도구 등록
server.tool("get-weather", { city: "string" }, async ({ city }) => {
  // 실제로는 날씨 API를 호출하겠지만, 예시니까 간단하게
  return {
    content: [
      { type: "text", text: `${city}의 현재 날씨: 맑음, 22도` }
    ]
  };
});

// 서버 시작
const transport = new StdioServerTransport();
await server.connect(transport);

이 정도면 기본 구조는 이해하셨죠? 자세한 내용은 MCP 공식 문서에서 확인할 수 있어요.

보안 주의사항

MCP 서버는 강력하지만, 그만큼 보안에 주의해야 해요.

MCP 보안 체크리스트

  • 신뢰할 수 있는 MCP 서버만 사용하세요 — 공식 패키지이거나, 소스 코드를 확인한 서버만 연결하세요
  • 접근 범위를 최소화하세요 — Filesystem MCP에 전체 하드디스크를 연결하지 말고, 필요한 폴더만 지정하세요
  • 토큰과 비밀번호 관리 — API 토큰은 환경 변수로 관리하고, settings.json에 직접 쓰지 마세요
  • 프로덕션 환경 주의 — 실서비스 DB에 연결할 때는 읽기 전용 권한만 부여하세요

MCP 서버는 여러분의 컴퓨터에서 실행되고, 외부 서비스에 접근할 수 있어요. 무턱대고 아무 서버나 설치하면 위험할 수 있으니, 항상 어떤 데이터에 접근하는지 확인하세요.

직접 해보기: Filesystem MCP 연결하기

  1. 프로젝트 폴더에 .claude/settings.json 파일을 만드세요
  2. Filesystem MCP 서버를 설정하세요 (위의 Step by Step 가이드 참고)
  3. 접근할 폴더 경로를 여러분의 문서 폴더로 설정하세요
  4. Claude Code를 실행하고 "이 폴더에 있는 파일 목록을 보여줘"라고 요청해보세요
  5. "가장 최근에 수정된 파일 3개를 알려줘" 같은 요청도 해보세요

Claude가 여러분의 파일 시스템에 접근해서 일하는 걸 체험해보세요!

이번 챕터 정리

  • MCP(Model Context Protocol)는 Claude와 외부 서비스를 연결하는 표준 규격이에요.
  • USB 허브처럼, MCP를 통해 GitHub, Microsoft Teams, DB, 파일 시스템 등 다양한 서비스에 접근할 수 있어요.
  • .claude/settings.json에서 MCP 서버를 설정하고, 여러 서버를 동시에 사용할 수 있어요.
  • 기존 MCP 서버를 설치하거나, SDK로 직접 만들 수도 있어요.
  • 보안에 주의하세요: 신뢰할 수 있는 서버만 사용하고, 접근 범위를 최소화하세요.
