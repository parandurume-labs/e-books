부록 A

용어 사전 (Glossary)

모르는 단어가 나오면 여기로 오세요

이 용어 사전 사용법

이 책을 읽으면서 "이 단어가 뭐였지?" 싶을 때 돌아올 페이지예요. 한글 가나다순 + 영문 알파벳순으로 정리했어요. 북마크 해두시면 편해요!

기호 / 파일명

용어 영어 설명
~ (물결표) tilde / home directory 내 홈 폴더를 가리키는 기호. 윈도우면 C:\Users\내이름, 맥이면 /Users/내이름이에요. 그래서 ~/.claude/CLAUDE.md는 홈 폴더 안의 .claude 폴더에 있는 파일이라는 뜻이죠.
.claude/settings.json .claude/settings.json 프로젝트의 Claude Code 설정 파일. permissions.deny에 Read(./.env)처럼 적으면 민감한 정보(API 키, 비밀번호 등)를 Claude가 읽지 못하게 막아요. Hook 설정도 이 파일에 넣어요.
.env .env 환경 변수를 모아 적어두는 파일. API 키나 비밀번호처럼 코드에 그대로 적으면 안 되는 값을 여기에 두고, 코드는 이 파일에서 값을 읽어요. 서버에서 도는 프로그램이 쓰는 방식이라, 브라우저에서만 도는 페이지는 이 파일을 읽지 못해요.
.mcp.json .mcp.json 저장소 루트에 두는 MCP 서버 설정 파일. 팀과 공유할 MCP 서버를 여기에 기록해요. 개인용 서버는 ~/.claude.json에 들어가요.
CLAUDE.md CLAUDE.md 프로젝트의 맥락, 규칙, 선호도를 Claude에게 알려주는 설정 파일. "이 프로젝트 설명서"라고 생각하면 돼요.
SKILL.md SKILL.md Claude에게 특정 전문가 역할을 부여하는 파일. 이 파일 하나가 슬래시 명령어가 돼요.

ㄱ

용어 영어 설명
권한 Permission Claude가 파일을 수정하거나 명령어를 실행하기 전에 사용자에게 허락을 구하는 시스템. 안전장치 역할을 해요.

ㅁ

용어 영어 설명
메모리 Memory Claude가 프로젝트와 사용자에 대해 알아둔 내용을 저장하는 체계. CLAUDE.md 파일이 이 체계의 프로젝트 메모리 파일이에요. 8장에서 자세히 다뤘어요.

ㅂ

용어 영어 설명
배포 Deploy 내 컴퓨터에서만 돌던 것을 인터넷에 올려서 누구나 볼 수 있게 하는 일. 12장에서 GitHub Pages, Vercel 같은 무료 방법을 다뤘어요.
브랜치 Branch git에서 원래 코드를 건드리지 않고 갈라져 나온 사본. 평행 세계라고 생각하면 돼요. 여기서 마음껏 고쳐도 원래 쪽은 그대로예요.

ㅅ

용어 영어 설명
생성형 AI Generative AI 기존 데이터를 학습해서 새로운 텍스트, 이미지, 코드를 만들어내는 AI. Claude가 바로 생성형 AI예요.
서브에이전트 Subagent Claude가 세부 작업을 맡기려고 불러내는 또 다른 Claude. 팀장이 대리에게 일을 나눠주는 것과 비슷해요. 13장에서 다뤘어요.
셸 스크립트 Shell Script 터미널에 한 줄씩 칠 명령어를 파일에 미리 적어둔 것. 보통 .sh로 끝나요. 맥·리눅스에서 그대로 돌고, 윈도우에서는 Git Bash나 WSL이 있어야 해요. 10장의 Hook 예시가 셸 스크립트예요.
스킬 Skills Claude에게 특정 분야의 전문성을 부여하는 기능. SKILL.md 파일로 정의하고, 슬래시 명령어로 호출해요.
슬래시 명령어 Slash Command /로 시작하는 명령어. /review, /ship 같은 특별한 기능을 빠르게 호출해요. 스마트폰의 앱 아이콘 같은 거예요.

ㅇ

용어 영어 설명
아티팩트 Artifact Claude.ai에서 생성된 문서, 코드, 표 등의 결과물. 대화와 별도로 편집하고 다운로드할 수 있어요.
에이전트 Agent 스스로 계획을 세우고, 도구를 사용하며, 목표를 달성하는 AI. 단순 대화를 넘어 "자율적으로 일하는" AI예요.

ㅈ

용어 영어 설명
저장소 Repository (repo) git이 변경 이력을 관리하는 프로젝트 폴더 하나. GitHub에 올라와 있는 것도 저장소예요. 「저장소 루트」는 그 폴더의 최상위를 뜻해요.
종료 코드 Exit Code 프로그램이 끝나면서 남기고 가는 숫자 하나. 0은 「잘 끝났다」, 0이 아니면 「문제가 있었다」예요. Claude Code의 Hook은 exit 2일 때만 도구를 차단해요. 10장에서 자세히 다뤘어요.

ㅋ

용어 영어 설명
커밋 Commit git으로 지금 상태를 저장해 두는 일. 게임의 세이브 포인트예요. 나중에 이 지점으로 돌아올 수 있어요.
컨텍스트 윈도우 Context Window Claude가 한 번에 기억하는 대화의 양. 책상 위 공간과 비슷해요. 공간이 한정돼 있어서, 대화가 길어지면 앞부분을 잊어요.

ㅌ

용어 영어 설명
터미널 Terminal 컴퓨터에게 글로 명령하는 까만 창. 마우스로 클릭하는 대신 키보드로 타이핑해요. 윈도우는 PowerShell, 맥은 터미널 앱이에요. 여는 법은 7장에 있어요.

ㅍ

용어 영어 설명
프로젝트 Project Claude.ai에서 관련 대화와 파일을 하나로 묶어 관리하는 기능. 업무별로 맥락을 나눠서 관리해요.
프롬프트 Prompt AI에게 주는 지시나 질문. "AI에게 하는 말" 전체를 프롬프트라고 해요. 프롬프트를 잘 쓸수록 좋은 결과를 얻어요.
프롬프트 엔지니어링 Prompt Engineering AI에게 더 좋은 결과를 얻기 위해 프롬프트를 전략적으로 작성하는 기술. 이 책 3장에서 자세히 다뤘어요.

ㅎ

용어 영어 설명
확장 사고 Extended Thinking Claude가 답변하기 전에 깊이 생각하는 기능. 복잡한 문제에서 더 정확한 답을 얻을 수 있어요.
환경 변수 Environment Variable 프로그램이 실행될 때 바깥에서 넘겨받는 값. 비밀번호나 API 키를 코드에 직접 적지 않고 이 자리에 두면, 코드를 남에게 보여줘도 비밀은 새지 않아요. 보통 .env 파일에 적어둬요.
훅 Hooks Claude가 도구를 사용하기 전이나 후에 자동으로 실행되는 명령어. "파일 저장 시 자동 포맷팅" 같은 자동화를 만들어요.

A~C

용어 영어 설명
API Application Programming Interface 프로그램과 프로그램이 대화하는 방법. 식당의 주문 시스템처럼, 정해진 방식으로 요청하면 결과를 받아요.
CI Continuous Integration 코드를 올릴 때마다 서버가 자동으로 테스트를 돌려주는 장치. 사람이 깜빡해도 기계가 대신 확인해줘요. 「지속적 통합」이라고 번역해요.
CLI Command Line Interface 키보드로 명령어를 입력해서 컴퓨터를 제어하는 방식. 터미널, 명령 프롬프트가 CLI예요. Claude Code가 CLI로 동작해요.
Claude.ai Claude.ai 웹 브라우저에서 Claude와 대화하는 서비스. 가장 쉽게 Claude를 사용하는 방법이에요.
Claude Code Claude Code 터미널에서 실행하는 Claude. 파일을 읽고, 코드를 작성하고, 명령어를 실행할 수 있는 강력한 AI 코딩 도구예요.
Claude Desktop Claude Desktop 데스크톱 앱으로 설치하는 Claude. MCP 서버를 연결해서 내 컴퓨터의 파일, DB 등과 직접 소통해요.

G~L

용어 영어 설명
git git 코드의 변경 이력을 관리하는 도구. 언제 누가 뭘 고쳤는지 남기고, 이전 상태로 돌아갈 수 있게 해줘요. 인터넷에 공개된 저장소를 통째로 받아올 때도 써요. git-scm.com에서 받아요. 9장, 13장에 나와요.
Git Bash Git Bash 윈도우에서 맥·리눅스식 명령어를 쓸 수 있게 해주는 터미널. Git을 설치하면 함께 깔려요. 이 책의 셸 스크립트 예시는 PowerShell 대신 여기서 실행하면 돼요.
JSON JavaScript Object Notation 설정값을 적는 표준 형식. 중괄호와 큰따옴표로 「이름: 값」을 짝지어 적어요. 규칙이 엄격해서 쉼표 하나만 틀려도 파일 전체가 안 읽혀요. 주석은 넣을 수 없고, 경로의 역슬래시는 \\처럼 두 번 써야 해요.

M~S

용어 영어 설명
MCP Model Context Protocol Claude와 외부 시스템(GitHub, DB, Microsoft Teams 등)을 연결하는 표준 규격. USB 포트처럼, 다양한 도구를 꽂아 쓸 수 있게 해줘요.
MCP 서버 MCP Server MCP 규격에 맞게 만들어진 외부 서비스 연결 프로그램. GitHub MCP 서버, PostgreSQL MCP 서버 등이 있어요.
Node.js Node.js JavaScript를 브라우저 밖에서 실행해주는 프로그램. Claude Code와 MCP 서버가 이걸 필요로 해요. nodejs.org에서 LTS 버전을 받아 설치하고, node -v로 확인해요.
npm Node Package Manager Node.js의 패키지 관리자. 앱스토어처럼 프로그램을 받아 설치해요. Node.js를 깔면 함께 들어와요. npm install -g ...의 -g는 컴퓨터 어디서든 쓰게 한다는 뜻이에요.
npx npx npm의 짝. 미리 설치해두지 않은 패키지를 그때그때 받아서 바로 실행해요. MCP 서버 설정에 npx가 나오는 이유예요. 설치는 npm, 즉석 실행은 npx라고 기억하면 돼요.
PR Pull Request 브랜치에서 한 일을 원래 브랜치에 합쳐 달라고 내는 요청서. 합치기 전에 사람이 한 번 확인할 자리를 만들어줘요. 13장에 나와요.
SDK Software Development Kit 개발자가 특정 서비스를 더 쉽게 쓰도록 만들어 놓은 도구 모음. Anthropic SDK로 Claude API를 쉽게 호출해요.

T~W

용어 영어 설명
토큰 Token AI가 텍스트를 처리하는 최소 단위. 한국어는 대략 한 글자가 1-2 토큰이에요 (2026년 7월 확인). 사용량과 비용이 토큰 단위로 계산돼요.
워크트리 Worktree Git의 기능으로, 같은 프로젝트를 여러 폴더에서 동시에 작업할 수 있게 해줘요. 멀티 에이전트 협업에 유용해요.
