프롬프트 레시피 모음

복사해서 바로 쓰세요

이 레시피 모음 사용법

각 프롬프트는 그대로 복사해서 사용할 수 있어요. [대괄호] 안의 내용만 내 상황에 맞게 바꾸면 돼요. 카테고리별로 정리했으니, 필요한 상황에 맞는 프롬프트를 찾아 쓰세요!

커스터마이즈 팁

모든 프롬프트에 이 세 가지를 추가하면 결과가 더 좋아져요:
1. 역할 지정: "당신은 [역할]입니다"
2. 출력 형식: "결과를 [형식]으로 작성해줘"
3. 톤/분위기: "[격식체/친근체]로 작성해줘"

이메일 / 커뮤니케이션

1. 미팅 요청 이메일

카테고리: 이메일 | 예상 결과: 격식 있지만 부담스럽지 않은 미팅 요청 이메일

당신은 비즈니스 커뮤니케이션 전문가입니다.

다음 조건으로 미팅 요청 이메일을 작성해주세요:
- 받는 사람: [이름/직함]
- 미팅 목적: [목적]
- 희망 일시: [날짜/시간대]
- 예상 소요 시간: [시간]
- 논의 사항: [주요 안건 2-3개]

톤: 정중하지만 딱딱하지 않게.
길이: 10줄 이내.
마지막에 "다른 시간이 편하시면 말씀해 주세요"와 같은 유연한 표현을 넣어주세요.

커스터마이즈: 상대방과의 관계(상사, 동료, 거래처)에 따라 톤을 조절하세요.

2. 정중한 거절 이메일

카테고리: 이메일 | 예상 결과: 관계를 해치지 않으면서 단호하게 거절하는 이메일

다음 상황에서 정중하게 거절하는 이메일을 작성해주세요:
- 거절 대상: [요청 내용]
- 거절 이유: [이유: 솔직하지만 상대를 배려하는 표현으로]
- 대안 제시: [가능하다면 대안을 제시]

조건:
- 감사 인사로 시작
- 거절 이유를 명확하지만 부드럽게
- 향후 협력 가능성은 열어두기
- 5-8줄 이내

커스터마이즈: 거절의 강도에 따라 "이번에는 어렵지만" vs "현재로서는 불가능합니다" 표현을 지정하세요.

3. 감사 이메일

카테고리: 이메일 | 예상 결과: 진심이 느껴지는 감사 이메일

다음 상황에 맞는 감사 이메일을 작성해주세요:
- 감사 대상: [누구에게]
- 감사 이유: [구체적인 도움/기여 내용]
- 그 도움의 영향: [어떤 결과로 이어졌는지]

조건:
- 구체적인 사례를 언급해서 형식적이지 않게
- 상대방의 노력을 인정하는 표현 포함
- 너무 과하지 않되, 진심이 느껴지게
- 5-7줄 이내

4. 공지사항 작성

카테고리: 커뮤니케이션 | 예상 결과: 명확하고 읽기 쉬운 사내 공지

다음 내용으로 사내 공지사항을 작성해주세요:
- 공지 제목: [제목]
- 주요 내용: [핵심 내용 3줄 요약]
- 적용 대상: [전 직원 / 특정 팀 / 특정 직급]
- 시행일: [날짜]
- 문의처: [담당자/부서]

형식:
- 핵심을 먼저 (결론 → 배경 순)
- 불릿 포인트로 주요 사항 정리
- 마지막에 FAQ 2-3개 추가

문서 / 보고서

5. 주간 보고서

카테고리: 보고서 | 예상 결과: 구조화된 주간 업무 보고서

다음 업무 내용을 주간 보고서 형식으로 정리해주세요:

이번 주 한 일:
[이번 주 수행한 업무를 자유롭게 나열]

형식:
1. 핵심 성과 (3줄 요약)
2. 상세 업무 내역 (업무별로 진행률 % 표시)
3. 이슈 및 리스크 (있으면)
4. 다음 주 계획
5. 지원 요청 사항 (있으면)

톤: 간결하고 객관적.
표로 정리할 수 있는 부분은 표로 만들어주세요.

6. 제안서 초안

카테고리: 문서 | 예상 결과: 설득력 있는 비즈니스 제안서

다음 내용으로 비즈니스 제안서 초안을 작성해주세요:
- 제안 배경: [왜 이것을 제안하는지]
- 현재 문제점: [현재 상황의 문제]
- 제안 내용: [구체적인 제안]
- 기대 효과: [정량적/정성적 효과]
- 필요 자원: [예산, 인력, 기간]
- 실행 계획: [단계별 일정]

조건:
- A4 2-3페이지 분량
- 각 섹션에 소제목
- 숫자와 데이터를 활용해서 설득력 높이기
- 리스크 및 대응 방안도 포함

7. 회의록 정리

카테고리: 문서 | 예상 결과: 깔끔하게 정리된 회의록

다음 회의 내용을 정리해주세요:

[회의 중 메모한 내용이나 녹취 요약을 여기에 붙여넣기]

정리 형식:
- 회의 일시: [날짜, 시간]
- 참석자: [이름들]
- 안건:
  1. [안건 1] 논의 내용 요약, 결정 사항
  2. [안건 2] 논의 내용 요약, 결정 사항
- Action Items: 담당자, 기한을 명시한 할 일 목록
- 다음 회의: [일정]

핵심만 추려서, 참석하지 않은 사람도 5분 안에 파악할 수 있게 작성해주세요.

8. 분석 보고서

카테고리: 보고서 | 예상 결과: 데이터 기반의 분석 보고서

다음 데이터/상황을 분석하고 보고서를 작성해주세요:

분석 대상: [무엇을 분석할지]
데이터/배경: [관련 데이터나 상황 설명]
분석 목적: [어떤 의사결정을 위한 분석인지]

보고서 구성:
1. Executive Summary (1문단)
2. 현황 분석 (데이터 해석)
3. 주요 발견 (인사이트 3-5개)
4. 원인 분석 (왜 이런 결과가 나왔는지)
5. 제언 (구체적인 액션 아이템)
6. 결론

표와 비교 항목을 적극 활용해주세요.

9. Excel 데이터 정리

카테고리: 데이터 | 예상 결과: 정리된 데이터 + 정리 규칙 설명

다음 데이터를 정리해주세요:

[데이터를 붙여넣기 또는 파일 설명]

정리 요청:
- 중복 데이터 제거
- 빈 값 처리 (삭제 또는 기본값)
- 날짜 형식 통일 (YYYY-MM-DD)
- 카테고리별 분류
- 이상치(outlier) 표시

출력: 정리된 데이터를 표 형식으로 보여주고,
어떤 규칙으로 정리했는지 간단히 설명해주세요.

10. 트렌드 분석

카테고리: 데이터 | 예상 결과: 패턴 발견 + 향후 예측

다음 시계열 데이터의 트렌드를 분석해주세요:

[월별/주별 데이터를 붙여넣기]

분석 요청:
1. 전체 추세 (상승/하락/횡보)
2. 계절성 패턴 (반복 패턴이 있는지)
3. 이상 포인트 (급등/급락 시점과 가능한 원인)
4. 향후 3개월 예측 (근거와 함께)
5. 주의사항 및 리스크

차트로 표현한다면 어떤 차트가 적합한지도 추천해주세요.

11. 대시보드 설계

카테고리: 데이터 | 예상 결과: 대시보드 레이아웃 + 핵심 지표 정의

다음 비즈니스를 위한 대시보드를 설계해주세요:

비즈니스: [업종/서비스]
대시보드 사용자: [경영진/마케팅팀/개발팀]
주요 목적: [무엇을 모니터링하고 싶은지]

포함할 내용:
1. 핵심 KPI 5-7개 (지표명, 계산 방법, 목표값)
2. 차트 구성 (어떤 차트를 어디에 배치할지)
3. 필터 옵션 (기간, 카테고리 등)
4. 알림 기준 (어떤 수치에서 경고를 울릴지)

레이아웃을 텍스트로 스케치해주세요.

12. 코드 리뷰 요청

카테고리: 개발 | 예상 결과: 체계적인 코드 리뷰 피드백

다음 코드를 리뷰해주세요:

[코드를 붙여넣기]

리뷰 기준:
1. 코드 품질 (가독성, 네이밍, 구조)
2. 버그 가능성 (잠재적 에러, 엣지 케이스)
3. 성능 (비효율적인 부분)
4. 보안 (취약점)
5. 테스트 용이성

형식:
- 잘한 점을 먼저 언급
- 개선 제안은 중요도 순 (심각/보통/사소)
- 각 제안에 수정 예시 코드 포함

14. API 설계

카테고리: 개발 | 예상 결과: RESTful API 스펙 문서

각 엔드포인트에 대해:

15. 테스트 코드 작성

포함할 테스트:

3. 에러 케이스 (잘못된 입력, 예외 상황)
4. 엣지 케이스 (특수 문자, 매우 큰 데이터 등)

각 테스트에 명확한 이름과 설명을 붙여주세요.

17. SNS 콘텐츠

카테고리: 마케팅 | 예상 결과: 플랫폼별 SNS 게시글

전달 내용: [핵심 메시지]
플랫폼: [인스타그램/트위터/링크드인/페이스북]
목적: [브랜드 인지도/참여 유도/트래픽 유도]

각 플랫폼에 맞게:
- 인스타그램: 감성적, 해시태그 10-15개, 이모지 활용
- 트위터(X): 280자 이내, 임팩트 있게, 해시태그 2-3개
- 링크드인: 전문적, 인사이트 중심, 질문으로 참여 유도
- 페이스북: 스토리텔링, 공유하고 싶게

A/B 테스트를 위해 각 플랫폼별 2개 버전을 만들어주세요.

18. 카피라이팅

사용 채널: [웹사이트/광고/이메일/브로셔]

요청:
1. 헤드라인 5개 (주목도 순위)
2. 서브 헤드라인 3개
