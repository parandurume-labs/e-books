CHAPTER 4

Claude.ai 200% 활용하기

대화만 하면 끝? 아직 절반도 못 쓴 거예요

Claude.ai에 접속해서 "안녕"이라고 인사한 후... 뭘 해야 하지? 대부분 여기서 멈춥니다. 마치 스마트폰을 사서 전화 통화만 하는 것처럼요. 카메라, 지도, 음악, 결제 — 아직 엄청난 기능들이 남아 있거든요.

이번 챕터에서는 Claude.ai의 숨겨진(사실은 숨겨진 게 아니라 안 써본) 기능들을 하나씩 파헤쳐 볼 거예요.

Projects — 맥락을 기억하는 작업 공간

매번 새 대화를 시작할 때마다 "우리 회사는 이런 회사이고, 이번 프로젝트는 이런 거고..."를 반복 설명하는 게 귀찮지 않으셨나요? Projects는 이 문제를 해결해요.

Projects란?

Projects는 특정 업무나 주제에 대한 전용 작업 공간이에요. 여기에 파일을 올리고, Custom Instructions(맞춤 지시)을 설정해 두면, 그 프로젝트 안에서 하는 모든 대화에 자동으로 적용돼요.

  • 파일 첨부 — 참고 문서, 데이터, 기존 보고서 등을 미리 올려두기
  • Custom Instructions — "항상 격식체로 써줘", "우리 회사 용어를 사용해줘" 같은 기본 규칙 설정
  • 대화 히스토리 — 프로젝트 안에서 나눈 대화들이 모여있어서 맥락이 유지됨

실전 시나리오: 매주 보고서를 쓰는 마케터 이주임

이주임은 매주 금요일 마케팅 주간 보고서를 써야 해요. 예전에는 매번 새 대화를 시작하고, 회사 배경부터 다시 설명했어요. 이제는 이렇게 합니다:

  1. "마케팅 주간보고" 프로젝트 생성
  2. Custom Instructions에 입력: "나는 ABC 화장품의 디지털 마케팅 담당이야. 보고서는 경영진 대상, 격식체, 핵심 성과→채널별 실적→다음 주 계획 순서로 써줘. 표와 수치를 적극 활용해."
  3. 참고 파일로 지난 주 보고서, 마케팅 KPI 기준표를 업로드
  4. 매주 금요일, 이번 주 데이터만 붙여넣기하고 "이번 주 보고서 작성해줘"라고만 하면 끝!

Artifacts — AI가 만든 결과물을 바로 활용

Claude.ai에서 코드나 문서, 다이어그램을 요청하면 대화창에 텍스트로만 나오는 게 아니에요. Artifacts라는 별도 패널에 결과물이 생성돼요. 이게 왜 좋냐면요:

  • 코드 — 실행 가능한 형태로 코드가 표시됨. 복사 한 번으로 바로 사용
  • 문서 — 마크다운 문서가 깔끔하게 렌더링됨
  • 웹 페이지 — HTML/CSS/JS를 바로 미리보기할 수 있음
  • 다이어그램 — Mermaid, SVG로 시각적 다이어그램 생성
  • 수정 요청 — "3번째 열을 삭제해줘", "색상을 파란색으로 바꿔줘" 같은 부분 수정 가능
  • 버전 관리 — 수정할 때마다 이전 버전을 유지해서 되돌리기 가능

Artifacts 활용 팁

"간단한 웹 페이지 만들어줘"라고 해보세요. HTML, CSS, JavaScript가 포함된 완성된 웹 페이지가 Artifact로 생성되고, 바로 미리보기까지 할 수 있어요. 프로토타입을 만들 때 엄청 유용해요.

파일 업로드 — 문서를 던지고 일을 시키기

Claude.ai의 가장 강력한 기능 중 하나예요. 파일을 올리고, 그 파일에 대해 일을 시킬 수 있어요. 그냥 읽어달라고 하는 게 아니에요 — 분석하고, 추출하고, 변환하고, 새로운 것을 만들어 달라고 할 수 있어요.

지원하는 파일 형식

  • PDF — 계약서, 논문, 보고서, 매뉴얼
  • 텍스트 파일 — .txt, .md, .csv
  • 코드 파일 — .py, .js, .html 등
  • 이미지 — 스크린샷, 사진, 차트 이미지
  • 스프레드시트 — .csv 형태의 데이터

파일 업로드 + 지시 예시

[계약서.pdf 업로드 후]
"이 계약서에서 우리 회사(을)에게 불리한 조항 3개를 찾아줘. 각 조항에 대해 왜 불리한지 설명하고, 수정 제안까지 해줘. 표 형식으로 정리해줘."

이미지 분석 예시

[경쟁사 웹사이트 스크린샷 업로드 후]
"이 웹사이트의 UI/UX를 분석해줘. 좋은 점 3개, 개선할 점 3개를 알려주고, 우리 웹사이트에 적용할 수 있는 아이디어를 제안해줘."

대화 전략 — 한 번에 끝내지 말고 대화하기

많은 사람들이 AI에게 한 번에 완벽한 결과를 기대해요. 하지만 AI 활용의 진짜 고수들은 대화를 통해 결과물을 발전시켜요.

쉬운 비유

디자이너에게 로고를 부탁한다고 생각해 보세요. 처음에 시안이 나오면 "음, 색감은 좋은데 폰트를 바꿔보자"라고 하죠. 그러면 수정본이 나오고, "이번엔 크기를 좀 줄여보자"라고 하고... 이런 반복을 통해 완성작이 나오잖아요. AI도 똑같아요. 첫 결과물은 시안이에요!

효과적인 대화 전략 4단계

  1. 첫 지시 — 4원칙(구체성, 역할, 맥락, 형식)을 적용한 초기 지시
  2. 피드백 — 결과물의 좋은 점과 바꾸고 싶은 점을 구체적으로 말하기
  3. 수정 — "2번 항목을 더 자세히", "톤을 좀 더 밝게", "이 부분은 삭제해줘"
  4. 완성 — 만족스러운 결과물이 나올 때까지 2-3번 반복

대화 중에 방향 전환도 OK!

"아, 잠깐. 생각해 보니까 보고서가 아니라 발표 슬라이드 형식이 더 낫겠다. 지금까지 만든 내용을 발표 슬라이드 텍스트로 바꿔줘." — 이런 것도 가능해요. AI는 대화 맥락을 기억하고 있으니까요.

Pro 기능 활용

무료 플랜으로도 많은 것을 할 수 있지만, Pro 플랜($20/월)을 쓰면 추가 기능을 활용할 수 있어요.

Extended Thinking (깊은 사고 모드)

복잡한 문제를 풀 때 Claude가 "생각하는 과정"을 보여주는 기능이에요. 수학 문제, 논리 퍼즐, 복잡한 분석 같은 걸 할 때 정확도가 확 올라가요.

Extended Thinking이 빛나는 순간들:

  • 복잡한 사업 계획서의 재무 모델 검토
  • 법적 문서의 논리적 허점 분석
  • 여러 요인을 고려한 의사결정 (예: 사무실 이전 검토)
  • 코드의 버그를 찾을 때

대용량 컨텍스트 활용

Claude는 매우 긴 문서도 한 번에 읽을 수 있어요. 200페이지짜리 계약서, 10만 줄의 코드, 수백 개의 고객 리뷰 — 이런 것들을 통째로 올려서 분석을 시킬 수 있다는 거예요. 사람이 이걸 읽으려면 며칠이 걸리는 걸 Claude는 몇 초 만에 해요.

대용량 분석 예시

[고객 리뷰 500개가 담긴 CSV 업로드 후]
"이 고객 리뷰 데이터를 분석해줘. 1) 긍정/부정 비율, 2) 가장 많이 언급된 키워드 TOP 10, 3) 불만 사항 카테고리별 분류, 4) 즉시 개선 가능한 사항 3개 추천. 표로 정리해줘."

실습: Claude.ai 프로젝트 만들기

  1. Claude.ai에 로그인하고 좌측 메뉴에서 "Projects"를 클릭하세요
  2. 새 프로젝트를 만드세요 — 이름을 자신의 주요 업무로 설정 (예: "주간 마케팅 보고", "고객 응대 매뉴얼")
  3. Custom Instructions를 설정하세요 — 자신의 역할, 회사 배경, 선호하는 스타일을 입력
  4. 관련 파일을 업로드하세요 — 기존 보고서, 참고 문서, 데이터 등
  5. 프로젝트 안에서 대화를 시작하세요 — 맥락 설명 없이 바로 업무 지시!

첫 프로젝트를 만들어 보고, 맥락이 자동으로 적용되는 편리함을 직접 느껴보세요.

잠깐, 정리!

  • Projects — 맥락을 기억하는 작업 공간. 파일 + Custom Instructions로 매번 설명 불필요
  • Artifacts — 코드, 문서, 웹 페이지를 별도 패널에서 바로 확인 + 수정
  • 파일 업로드 — PDF, CSV, 이미지를 올려서 분석, 추출, 변환 가능
  • 대화 전략 — 첫 지시 → 피드백 → 수정 → 완성 (반복!)
  • Pro 기능 — Extended Thinking으로 복잡한 분석, 대용량 컨텍스트 활용
