CHAPTER 5

Claude Desktop으로 내 컴퓨터와 연결하기

Claude가 내 파일을 직접 읽고 쓸 수 있다고요?

Claude.ai에서 "내 바탕화면의 Excel 파일을 분석해줘"라고 하면... 당연히 안 됩니다. 웹 브라우저 안에 갇혀 있으니까요. 파일을 일일이 업로드해야 하죠. 하지만 만약 Claude가 여러분의 컴퓨터에 직접 앉아서, 파일을 열어보고, 데이터베이스를 조회하고, 심지어 Teams 메시지까지 보낼 수 있다면?

그게 바로 Claude Desktop이에요.

Claude Desktop이란?

Claude Desktop은 Mac과 Windows에 설치하는 데스크톱 애플리케이션이에요. 겉보기에는 Claude.ai와 비슷하게 생겼지만, 결정적인 차이가 하나 있어요.

Claude Desktop의 핵심 차이점

MCP(Model Context Protocol)를 통해 외부 도구와 연결할 수 있다는 것. Claude.ai가 "대화만 잘하는 AI"라면, Claude Desktop은 "대화도 하고 직접 행동도 하는 AI"예요.

설치 방법

  1. claude.ai/download에서 Mac 또는 Windows 버전 다운로드
  2. 설치 파일 실행 후 안내에 따라 설치
  3. Claude.ai와 같은 계정으로 로그인
  4. 기본 대화 기능은 바로 사용 가능!

여기까지는 그냥 "데스크톱 버전의 Claude.ai"예요. 진짜 마법은 MCP를 연결할 때 시작돼요.

MCP 서버 — Claude의 능력 확장

MCP란?

MCP(Model Context Protocol)는 Anthropic이 만든 개방형 프로토콜이에요. 쉽게 말해서, Claude에게 새로운 능력을 추가할 수 있는 규격이에요.

쉬운 비유

스마트폰에 앱을 설치하면 새로운 기능이 생기잖아요? 카카오맵 설치하면 길 찾기가 되고, 배달의민족 설치하면 음식 주문이 되고. MCP는 Claude에게 설치하는 "앱"이라고 생각하시면 돼요. Filesystem MCP를 설치하면 파일을 다룰 수 있게 되고, GitHub MCP를 설치하면 코드 저장소를 관리할 수 있게 돼요.

자주 쓰는 MCP 서버들

MCP 서버는 이미 수백 개가 만들어져 있어요. 그중에서 가장 실용적인 것들을 소개할게요.

Filesystem — 로컬 파일 읽기/쓰기

가장 기본이면서 가장 강력한 MCP 서버예요. 지정한 폴더 안의 파일을 Claude가 직접 읽고, 수정하고, 새로 만들 수 있어요.

활용 예시: "바탕화면의 '매출데이터.csv'를 읽어서 월별 매출 추이를 분석하고, 요약 보고서를 '매출분석.md'로 저장해줘."

Database (SQLite, PostgreSQL) — DB 조회

데이터베이스에 직접 연결해서 SQL 쿼리를 실행할 수 있어요. "지난달 가입한 유저 수 알려줘"라고 자연어로 물어보면, Claude가 알아서 SQL을 짜서 실행해요.

GitHub — 이슈/PR 관리

GitHub 저장소의 이슈를 확인하고, Pull Request를 검토하고, 코드 변경 사항을 요약할 수 있어요.

Microsoft Teams — 메시지 보내기

Teams 채널의 메시지를 읽거나, Claude가 직접 메시지를 보낼 수 있어요. "오늘 공지 채널에서 논의된 내용 요약해줘" 같은 것도 가능해요.

Slack, Discord를 쓰는 팀이라면 그쪽 MCP 서버로 그대로 대체됩니다. 도구만 바뀌고 쓰는 방식은 같아요.

Google Drive — 문서 접근

Google Drive의 문서, 스프레드시트, 프레젠테이션에 접근해서 내용을 분석하거나 수정할 수 있어요.

MCP 서버 설정하기

MCP 서버를 연결하는 건 생각보다 간단해요. claude_desktop_config.json이라는 설정 파일에 원하는 MCP 서버 정보를 적어주면 돼요.

설정 파일 위치

  • Mac: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Filesystem MCP 서버 설정 예시

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\사용자이름\\Desktop",
        "C:\\Users\\사용자이름\\Documents"
      ]
    }
  }
}

이 설정을 하면 Claude Desktop이 바탕화면과 문서 폴더의 파일을 읽고 쓸 수 있게 돼요.

보안 주의!

MCP는 Claude에게 실제 시스템 접근 권한을 주는 거예요. 꼭 필요한 폴더만 지정하고, 민감한 정보가 있는 폴더는 제외하세요. Claude가 파일을 읽을 때마다 확인 메시지가 뜨니까 실수로 중요한 파일을 건드리는 일은 없지만, 항상 주의하는 게 좋아요.

여러 MCP 서버를 함께 쓰는 예시

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\사용자이름\\Desktop"
      ]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_여러분의토큰"
      }
    }
  }
}

실무 워크플로: MCP로 연결된 Claude Desktop 활용

  1. 아침: "바탕화면의 오늘 할일.txt를 읽어줘" → 할 일 확인
  2. 오전: "Documents 폴더의 매출데이터.csv를 분석해서 보고서 초안 만들어줘" → 데이터 분석
  3. 오후: "GitHub에서 이번 주 등록된 이슈 목록 보여줘" → 개발 이슈 관리
  4. 퇴근 전: "오늘 한 일을 정리해서 업무일지.md로 저장해줘" → 자동 기록

실습: Claude Desktop + Filesystem MCP 연결하기

  1. Claude Desktop을 설치하세요 (아직 안 했다면)
  2. Node.js가 설치되어 있는지 확인하세요 (터미널에서 node --version 입력)
  3. 위에서 안내한 경로의 claude_desktop_config.json 파일을 만들고 Filesystem 설정을 입력하세요
  4. Claude Desktop을 재시작하세요
  5. 대화창에 "내 바탕화면에 어떤 파일들이 있는지 보여줘"라고 입력하세요
  6. 파일 목록이 나오면 성공! 이제 "그중에서 가장 최근 파일의 내용을 요약해줘"도 시도해 보세요

잠깐, 정리!

  • Claude Desktop = Claude.ai + 로컬 시스템 접근 능력
  • MCP는 Claude에게 새 능력을 추가하는 "앱 스토어" 같은 것
  • Filesystem MCP로 로컬 파일을 읽고 쓸 수 있다
  • GitHub, Microsoft Teams, DB 등 다양한 MCP 서버를 연결할 수 있다
  • 설정은 claude_desktop_config.json에서 JSON으로 간단하게
  • 보안을 위해 필요한 폴더만 지정하자
