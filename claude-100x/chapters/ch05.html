CHAPTER 5

Claude Desktop으로 내 컴퓨터와 연결하기

Claude가 내 파일을 직접 읽고 쓸 수 있다고요?

Claude.ai에서 "내 바탕화면의 Excel 파일을 분석해줘"라고 하면... 당연히 안 됩니다. 웹 브라우저 안에 갇혀 있으니까요. 파일을 일일이 업로드해야 하죠. 하지만 만약 Claude가 내 컴퓨터에 직접 앉아서, 파일을 열어보고, 데이터베이스를 조회하고, 심지어 Teams 메시지까지 보낼 수 있다면?

그게 바로 Claude Desktop이에요.

Claude Desktop이란?

Claude Desktop은 Mac과 Windows에 설치하는 데스크톱 애플리케이션이에요. 겉보기에는 Claude.ai와 비슷하게 생겼지만, 결정적인 차이가 하나 있어요.

Claude Desktop의 핵심 차이점

MCP(Model Context Protocol)를 통해 외부 도구와 연결할 수 있다는 것. Claude.ai가 "대화만 잘하는 AI"라면, Claude Desktop은 "대화도 하고 직접 행동도 하는 AI"예요.

설치 방법

  1. claude.ai/download에서 Mac 또는 Windows 버전 다운로드
  2. 설치 파일 실행 후 안내에 따라 설치
  3. Claude.ai와 같은 계정으로 로그인
  4. 기본 대화 기능은 바로 사용 가능!

여기까지는 그냥 "데스크톱 버전의 Claude.ai"예요. 진짜 마법은 MCP를 연결할 때 시작돼요.

MCP 서버: Claude의 능력 확장

MCP란?

MCP(Model Context Protocol)는 Anthropic이 만든 개방형 프로토콜이에요. 쉽게 말해서, Claude에게 새로운 능력을 더해주는 규격이에요.

쉬운 비유

스마트폰에 앱을 설치하면 새로운 기능이 생기잖아요? 카카오맵 설치하면 길 찾기가 되고, 배달의민족 설치하면 음식 주문이 되고. MCP는 Claude에게 설치하는 "앱"이라고 생각하시면 돼요. Filesystem MCP를 설치하면 파일을 다루게 되고, GitHub MCP를 설치하면 코드 저장소를 관리하게 돼요.

자주 쓰는 MCP 서버들

MCP 서버는 이미 수백 개가 만들어져 있어요. 그중에서 가장 실용적인 것들을 소개할게요.

Filesystem: 로컬 파일 읽기/쓰기

가장 기본이면서 가장 강력한 MCP 서버예요. 지정한 폴더 안의 파일을 Claude가 직접 읽고, 수정하고, 새로 만들어요.

활용 예시: "바탕화면의 '매출데이터.csv'를 읽어서 월별 매출 추이를 분석하고, 요약 보고서를 '매출분석.md'로 저장해줘."

Database (SQLite, PostgreSQL): DB 조회

데이터베이스에 직접 연결해서 SQL 쿼리를 실행해요. "지난달 가입한 유저 수 알려줘"라고 자연어로 물어보면, Claude가 알아서 SQL을 짜서 실행해요.

GitHub: 이슈/PR 관리

GitHub 저장소의 이슈를 확인하고, Pull Request를 검토하고, 코드 변경 사항을 요약해요.

Microsoft Teams: 메시지 보내기

Teams 채널의 메시지를 읽거나, Claude가 직접 메시지를 보내요. "오늘 공지 채널에서 논의된 내용 요약해줘" 같은 것도 가능해요.

Slack, Discord를 쓰는 팀이라면 그쪽 MCP 서버로 그대로 대체됩니다. 도구만 바뀌고 쓰는 방식은 같아요.

Google Drive: 문서 접근

Google Drive의 문서, 스프레드시트, 프레젠테이션에 접근해서 내용을 분석하거나 수정해요.

여기서부터는 준비물이 필요해요

지금까지는 설치하고 클릭하는 것만으로 됐는데, 여기서부터는 터미널과 Node.js가 있어야 해요. 둘 다 처음 듣는 말이라면 7장의 「터미널 기초」와 Node.js 안내를 먼저 보고 오세요. 터미널 여는 법부터 차근차근 나와요. 그거 하나 보고 오면 이 절이 훨씬 쉬워져요.

MCP 서버 설정하기

MCP 서버를 연결하는 건 생각보다 간단해요. claude_desktop_config.json이라는 설정 파일에 원하는 MCP 서버 정보를 적어주면 돼요.

설정 파일 위치

  • Mac: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

맥 경로 앞의 ~는 내 홈 폴더를 가리키는 기호예요. 맥이면 /Users/내이름이죠. 윈도우의 %APPDATA%는 프로그램 설정이 모이는 숨은 폴더인데, 글자 그대로 붙여넣으면 컴퓨터가 알아서 찾아가요.

설정 파일을 실제로 만드는 법

"파일을 만들라"는 말이 제일 막막하죠. 윈도우 기준으로 하나씩 짚어볼게요.

  1. 탐색기를 열고 위쪽 주소창에 %APPDATA%\Claude를 그대로 붙여넣은 다음 엔터를 누르세요. Claude Desktop의 설정 폴더로 바로 들어가요.
  2. 거기에 claude_desktop_config.json이 이미 있으면, 오른쪽 클릭 → 「연결 프로그램」 → 메모장으로 여세요.
  3. 없으면 메모장을 새로 열어 내용을 적고, 「파일 → 다른 이름으로 저장」에서 「파일 형식」을 「모든 파일」로 바꾼 다음 이름을 claude_desktop_config.json으로 적어 이 폴더에 저장하세요.

3번의 「모든 파일」이 중요해요. 그냥 저장하면 뒤에 .txt가 몰래 붙어서 Claude가 파일을 못 찾아요. 그리고 워드나 한글로 열면 글꼴과 서식이 섞여 들어가 파일이 깨져요. 메모장처럼 글자만 저장하는 편집기를 쓰세요. 맥이라면 텍스트편집기를 열고 「포맷 → 일반 텍스트 만들기」를 고른 뒤 위에 적힌 맥 경로에 저장하면 돼요.

Filesystem MCP 서버 설정 예시

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\사용자이름\\Desktop",
        "C:\\Users\\사용자이름\\Documents"
      ]
    }
  }
}

이 설정을 하면 Claude Desktop이 바탕화면과 문서 폴더의 파일을 읽고 쓰게 돼요.

낯선 게 두 개 보일 거예요. 하나는 npx인데, 미리 설치해두지 않은 패키지를 그때그때 받아서 바로 실행하는 명령이에요. Node.js를 설치하면 함께 깔리니까 따로 준비할 건 없어요.

다른 하나는 경로의 역슬래시가 \\처럼 두 번씩 적혀 있다는 점이에요. 오타가 아니에요. JSON에서는 역슬래시를 두 번 써야 한 번으로 읽혀요. 한 번만 쓰면 파일 전체가 깨지니 보이는 대로 두 번 적으세요. 맥 경로는 /Users/사용자이름/Desktop처럼 슬래시라서 이 문제가 없어요.

보안 주의!

MCP는 Claude에게 실제 시스템 접근 권한을 주는 거예요. 꼭 필요한 폴더만 지정하고, 민감한 정보가 있는 폴더는 제외하세요. 확인 창이 뜨긴 하지만 거기에는 "이 대화에서 항상 허용"이 있어서, 한 번 허용하면 다음부터는 묻지 않아요. 그러니 폴더를 지정하는 이 단계에서 걸러야 합니다.

여러 MCP 서버를 함께 쓰는 예시

서버를 더 붙이고 싶으면 mcpServers 안에 항목을 하나 더 적으면 돼요. 생김새는 이래요.

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\사용자이름\\Desktop"
      ]
    },
    "두-번째-서버": {
      "command": "npx",
      "args": ["-y", "설치할-MCP-서버-패키지-이름"],
      "env": {
        "API_TOKEN": "발급받은토큰"
      }
    }
  }
}

패키지 이름과 env에 넣을 값은 서버마다 달라요. 그 서버의 안내 문서에 적힌 그대로 채우면 됩니다. MCP 서버 목록은 계속 바뀌어서 어제 쓰던 패키지가 오늘 없어지기도 하니(2026년 7월 기준), 설치 전에 지금도 관리되는 패키지인지 한 번 확인하세요.

실무 워크플로: MCP로 연결된 Claude Desktop 활용

  1. 아침: "바탕화면의 오늘 할일.txt를 읽어줘" → 할 일 확인
  2. 오전: "Documents 폴더의 매출데이터.csv를 분석해서 보고서 초안 만들어줘" → 데이터 분석
  3. 오후: "GitHub에서 이번 주 등록된 이슈 목록 보여줘" → 개발 이슈 관리
  4. 퇴근 전: "오늘 한 일을 정리해서 업무일지.md로 저장해줘" → 자동 기록

실습: Claude Desktop + Filesystem MCP 연결하기

  1. Claude Desktop을 설치하세요 (아직 안 했다면)
  2. Node.js가 설치되어 있는지 확인하세요. 터미널을 열고 node --version을 입력하면 돼요. 터미널을 여는 법과 Node.js 설치는 7장에 있으니, 처음이라면 거기부터 보고 오세요
  3. 위의 「설정 파일을 실제로 만드는 법」대로 claude_desktop_config.json을 만들고 Filesystem 설정을 입력하세요
  4. Claude Desktop을 재시작하세요
  5. 대화창에 "내 바탕화면에 어떤 파일들이 있는지 보여줘"라고 입력하세요
  6. 파일 목록이 나오면 성공! 이제 "그중에서 가장 최근 파일의 내용을 요약해줘"도 시도해 보세요

잠깐, 정리!

  • Claude Desktop = Claude.ai + 로컬 시스템 접근 능력
  • MCP는 Claude에게 새 능력을 추가하는 "앱 스토어" 같은 것
  • Filesystem MCP로 로컬 파일을 읽고 쓴다
  • GitHub, Microsoft Teams, DB 등 다양한 MCP 서버를 연결한다
  • 설정은 claude_desktop_config.json에서 JSON으로 간단하게
  • 보안을 위해 필요한 폴더만 지정하자
