CHAPTER 9

Skills: AI에게 전문성을 가르치다

슬래시 하나로 전문가를 소환하세요

같은 Claude인데 왜 다를까?

같은 Claude Code를 쓰는 두 사람이 있어요.

A씨: "이 코드 좀 봐줘." → Claude가 코드를 읽고 "괜찮아 보입니다" 하고 끝.

B씨: /review → Claude가 보안 취약점, 성능 문제, 코딩 컨벤션 위반, 테스트 커버리지까지 항목별로 분석한 리포트를 만들어줘요.

같은 Claude인데, 어떻게 이렇게 결과가 달라질까요?

비밀은 스킬(Skill)에 있어요.

B씨의 Claude에는 "코드 리뷰 전문가" 스킬이 설치되어 있었던 거예요. 이 스킬이 Claude에게 "코드 리뷰를 할 때는 이런 순서로, 이런 항목을 체크하고, 이런 형식으로 보고해"라는 전문적인 지시사항을 알려주거든요.

스킬이란 뭔가요?

스킬은 Claude에게 특정 작업을 수행하는 방법을 알려주는 매뉴얼이에요.

셰프에게 레시피를 주는 것

Claude는 요리를 잘하는 셰프예요. 하지만 레시피 없이 "뭐 좀 만들어줘"라고 하면, 그냥 무난한 요리를 만들 거예요. 그런데 "미쉐린 3스타 레시피"를 주면? 같은 재료로 완전히 다른 수준의 요리를 만들어내요. 스킬이 바로 그 레시피예요.

기술적으로 보면, 스킬은 SKILL.md라는 마크다운 파일이에요. 이 파일에 Claude가 따라야 할 지시사항이 적혀 있고, 사용자가 슬래시 명령어(/skill-name)로 실행하면 Claude가 그 지시사항을 읽고 따라요.

SKILL.md의 구조

스킬 파일은 두 부분으로 나뉘어요:

1. Frontmatter: 스킬의 이름표

파일 맨 위에 ---로 감싼 메타데이터가 있어요:

---
name: hello-world
description: "인사를 건네는 간단한 스킬"
---

2. Instructions: 실제 지시사항

Frontmatter 아래에 Claude가 따라야 할 내용을 마크다운으로 적어요:

---
name: hello-world
description: "인사를 건네는 간단한 스킬"
---

# Hello World 스킬

사용자에게 한국어로 따뜻한 인사를 건네세요.

## 규칙
1. 반드시 한국어로 인사하세요
2. 현재 시간대에 맞는 인사말을 사용하세요
   - 아침: "좋은 아침이에요!"
   - 낮: "안녕하세요!"
   - 저녁: "좋은 저녁이에요!"
3. 인사 후 오늘의 응원 메시지를 하나 추가하세요

이게 전부예요! 이 파일 하나가 Claude를 "인사 전문가"로 만들어줘요.

슬래시 명령어로 스킬 실행하기

스킬이 설치되면, 터미널에서 슬래시(/)와 스킬 이름을 입력하면 바로 실행돼요:

# Claude Code 대화 중에...
/hello-world          # 인사 스킬 실행
/review               # 코드 리뷰 스킬
/ship                 # 배포 준비 스킬
/qa                   # QA 테스트 스킬
/office-hours         # YC 오피스아워 스킬

슬래시를 입력하면 사용 가능한 스킬 목록이 자동완성으로 나타나요. 마치 채팅 앱에서 이모지를 고르는 것처럼 편리하죠.

스킬의 힘

스킬 없이 "코드 리뷰해줘"라고 하면, Claude가 알아서 적당히 해줘요. 하지만 /review 스킬을 쓰면, 보안 감사, 성능 분석, 코딩 컨벤션 체크, 테스트 커버리지 확인까지 체계적으로 해줘요. 같은 요청이라도 결과의 깊이가 완전히 달라요.

커뮤니티 스킬 설치하기

스킬을 직접 만들 수도 있지만, 이미 잘 만들어진 스킬 패키지를 설치하는 게 더 빨라요. 요리를 배우기 전에 먼저 유명 셰프의 레시피를 써보는 것처럼요.

gstack: Garry Tan의 스킬 패키지

gstack은 Y Combinator의 CEO Garry Tan이 공개한 스킬 패키지예요. 20개 이상의 전문가 역할이 들어 있어요:

  • /review: 전문가 수준의 코드 리뷰
  • /ship: 배포 준비 워크플로우
  • /qa: QA 테스트
  • /office-hours: 스타트업 멘토링
  • /design-review: 디자인 리뷰
  • /investigate: 버그 조사
  • /cso: 보안 감사
  • 그 외 다수...

설치 방법

# 1. 저장소를 클론하고 설치 스크립트를 돌립니다
#    (2026년 7월 확인 · 공식 저장소는 garrytan/gstack 입니다)
git clone --single-branch --depth 1   https://github.com/garrytan/gstack.git ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup

# 2. 잘 깔렸는지 확인합니다
#    Claude Code에서 /gstack-upgrade 를 쳐 보면 버전이 나와요

# 3. 프로젝트의 CLAUDE.md에 등록합니다
## Skills
- gstack이 ~/.claude/skills/gstack 에 설치되어 있습니다

Awesome Agent Skills

gstack 외에도 커뮤니티에서 만든 다양한 스킬들이 있어요. GitHub에서 "awesome claude skills"로 검색하면 유용한 스킬 모음이 줄줄이 나와요.

나만의 스킬 만들기

커뮤니티 스킬도 좋지만, 내 업무에 딱 맞는 스킬을 직접 만들 수도 있어요.

Step by Step: 나만의 코드 리뷰 스킬 만들기

  1. 스킬 폴더 만들기 
    mkdir -p ~/.claude/skills/my-review
  2. SKILL.md 파일 만들기 
    # ~/.claude/skills/my-review/SKILL.md

---
name: my-review
description: "우리 팀 스타일로 코드 리뷰하기"
---

# 코드 리뷰 스킬

변경된 코드를 우리 팀의 기준으로 리뷰합니다.

## 리뷰 순서
1. **변경 사항 요약** — 무엇이 바뀌었는지 한 줄로
2. **보안 체크** — SQL 인젝션, XSS 등 취약점 확인
3. **성능 체크** — 불필요한 렌더링, N+1 쿼리 확인
4. **코딩 스타일** — 팀 컨벤션 준수 여부
5. **테스트** — 테스트가 충분한지 확인

## 출력 형식
- 각 항목은 통과/주의/문제 로 표시
- 문제가 있으면 수정 제안 포함
- 전체 점수를 10점 만점으로
  3. Claude Code에서 테스트 
    # Claude Code 대화에서
/my-review

이게 전부예요! 파일 하나만 만들면, 나만의 전문가 스킬이 완성돼요.

시나리오: 비개발자를 위한 스킬 아이디어

  • weekly-report: 이번 주 작업 내용을 정해진 양식으로 정리
  • email-draft: 상황에 맞는 비즈니스 이메일 초안 작성
  • meeting-notes: 회의록을 정해진 템플릿으로 정리
  • data-summary: CSV 데이터를 읽고 핵심 지표 요약

개발자가 아니어도 자신의 업무에 맞는 스킬을 만들 수 있어요!

직접 해보기: 스킬 체험

옵션 A: gstack 스킬 사용해보기

  1. gstack을 설치하세요 (위의 설치 방법 참고)
  2. 아무 프로젝트 폴더에서 Claude Code를 실행하세요
  3. /office-hours를 입력하고, 지금 하고 있는 프로젝트나 아이디어를 상담해보세요

옵션 B: 나만의 스킬 만들어보기

  1. ~/.claude/skills/greeting/ 폴더를 만드세요
  2. SKILL.md를 만들고, Claude가 나만의 방식으로 인사하도록 지시사항을 적어보세요
  3. Claude Code에서 /greeting을 실행해보세요

이번 챕터 정리

  • 스킬은 Claude에게 특정 작업 방법을 가르치는 SKILL.md 파일이에요.
  • 슬래시 명령어(/skill-name)로 스킬을 간편하게 실행해요.
  • gstack 같은 커뮤니티 스킬 패키지로 20개 이상의 전문가 역할을 바로 써요.
  • SKILL.md 파일 하나만 만들면 나만의 스킬이 완성돼요.
  • 같은 Claude라도 스킬에 따라 결과의 깊이가 완전히 달라져요.
