CHAPTER 4

설치하기

30초면 끝나요, 진짜로

앱스토어의 터미널 버전

앱스토어에서 앱 설치해본 적 있죠? 검색하고, "설치" 버튼 누르고, 끝. 그거랑 비슷한데, 터미널 버전이에요.

버튼 대신 명령어를 타이핑하는 것뿐이에요. 진짜 30초면 끝나요. (준비물 확인 시간 빼고요!)

Step 0: 준비물 확인

설치하기 전에, 필요한 도구들이 다 있는지 먼저 확인해볼게요. 터미널을 열고 아래 명령어를 하나씩 쳐보세요.

Git 확인

터미널에 이렇게 타이핑하고 엔터:

git --version

성공: git version 2.43.0 같은 버전 번호가 나오면 OK!

실패: "command not found"가 나오면, git-scm.com에서 Git을 먼저 설치하세요.

Node.js 확인

node --version

성공: v20.11.0 같은 버전 번호가 나오면 OK! (v18 이상이면 돼요)

실패: nodejs.org에서 LTS 버전을 설치하세요.

Bun 확인

bun --version

성공: 1.1.30 같은 번호가 나오면 OK! (1.0 이상이면 돼요)

실패: bun.sh에 나온 한 줄을 터미널에 붙여넣으면 깔려요. gstack의 설치 스크립트가 Bun으로 돌아가서, 이게 없으면 마지막 단계에서 멈춰요.

Claude Code 확인

claude --version

성공: 버전 번호가 나오면 OK!

실패: 아직 안 깔린 거예요. 터미널에 이렇게 치면 됩니다.

npm install -g @anthropic-ai/claude-code

깔고 나서 터미널에 claude를 치면 브라우저가 열리면서 Anthropic 계정 로그인을 요구해요. 로그인까지 마쳐야 준비가 끝나요.

돈이 드는 부분을 먼저 말씀드릴게요

Claude Code를 계속 쓰려면 유료 플랜이나 API 크레딧이 필요해요. 무료로 잠깐 맛보고 끝나는 도구가 아니에요. 나중에 알고 서운하시면 안 되니까 여기서 적어둡니다. (2026년 7월 기준)

전부 OK인가요?

네 개 다 버전 번호가 나왔으면 Step 1로 넘어가세요. 하나라도 안 되면 그 도구를 먼저 깔고 오세요. Git·Node·Bun은 위 링크에서 받아 "다음 → 다음 → 완료"로 끝나요.

Step 1: gstack 설치 명령어

자, 이제 진짜 설치합니다. 터미널에 아래를 통째로 붙여넣고 엔터를 치세요. Claude Code 안이 아니라 그냥 터미널이에요.

git clone --single-branch --depth 1 \
  https://github.com/garrytan/gstack.git ~/.claude/skills/gstack

cd ~/.claude/skills/gstack && ./setup

두 줄이 하는 일은 이래요. 첫 줄이 gstack을 인터넷에서 내려받아 ~/.claude/skills/gstack에 놓고, 둘째 줄이 그 폴더로 들어가 설치 스크립트를 돌려요. 여기서 ~는 내 홈 폴더를 뜻해요. 윈도우면 C:\Users\내이름, 맥이면 /Users/내이름이에요.

잘 됐는지 어떻게 아나요

./setup이 끝나면 설치된 스킬 이름들이 화면에 주르륵 지나가요. 그러고 나서 이렇게 확인하면 됩니다.

cat ~/.claude/skills/gstack/VERSION

버전 번호(예: 1.60.1.0)가 나오면 성공이에요. (2026년 7월 확인)

윈도우에서 막히면

위 명령어는 맥·리눅스 기준이에요. 윈도우라면 PowerShell 말고 Git Bash에서 치세요. Git을 설치할 때 함께 깔리는 프로그램이고, 시작 메뉴에서 "Git Bash"로 찾으면 나와요. PowerShell에서는 ./setup이 안 돌아가요.

쉬운 비유

첫 줄은 레시피북을 주문해서 받는 것,
둘째 줄은 받은 책을 주방 선반에 꽂아 넣는 것이에요.
꽂아 넣어야 요리할 때 꺼내 쓸 수 있죠.

Step 2: 등록됐는지 확인하기

./setup이 대개 자동으로 등록해 줍니다. 확인만 하면 돼요.

등록이란, gstack 스킬이 Claude Code가 들여다보는 폴더에 놓이는 걸 말해요. 그 폴더가 ~/.claude/skills이고, gstack은 그 안의 ~/.claude/skills/gstack에 놓여요.

터미널에 이렇게 쳐서 확인하세요.

ls ~/.claude/skills/gstack

성공: 폴더 안의 파일 이름들이 주르륵 나오면 등록된 거예요.

실패: "No such file or directory"가 나오면 Step 1의 두 줄을 다시 돌려 보세요.

CLAUDE.md는 뭔가요?

CLAUDE.md는 Claude Code의 "설정 파일"이에요. "이런 규칙을 따라줘"라고 Claude Code에게 알려주는 파일이에요. 스마트폰의 "설정" 앱이라고 생각하면 돼요.

gstack을 쓰는 데는 이 파일을 직접 손댈 일이 없어요. ./setup이 스킬을 폴더에 놓아 주는 것으로 등록이 끝나거든요. 나중에 프로젝트마다 규칙을 따로 정하고 싶어지면 그때 만들면 돼요.

Step 3: 설치 확인 · /office-hours로 테스트!

설치가 잘 됐는지 확인하는 가장 좋은 방법은 직접 써보는 거예요.

Claude Code에서 이렇게 타이핑해보세요:

/office-hours

AI가 "어떤 아이디어나 프로젝트에 대해 이야기하고 싶으신가요?" 같은 질문을 하면 성공! gstack이 제대로 설치된 거예요.

"해당 스킬을 찾을 수 없습니다" 같은 에러가 나오면, Step 2의 확인을 다시 해보세요.

Windows 사용자 주의사항

Windows에서는 가끔 경로(path) 문제가 생길 수 있어요. 특히 한글 사용자명이 포함된 경로에서요.

만약 설치 중 에러가 발생하면:

  • 프로젝트 폴더를 C:\projects 같은 짧고 영문인 경로에 만들어보세요.
  • 관리자 권한으로 터미널을 열어보세요 (터미널 아이콘 → 우클릭 → "관리자 권한으로 실행").
  • 그래도 안 되면, 챕터 13(문제 해결)을 참고하세요.

(선택) 팀원과 공유하기

혼자 쓰는 것도 좋지만, 팀이 있다면 같이 쓰면 더 좋아요.

gstack은 각자 PC의 ~/.claude/skills/gstack에 깔려요. 그래서 팀원도 Step 1의 두 줄을 자기 PC에서 한 번 돌려야 해요. 대신 한 번 깔고 나면 같은 스킬 이름을 팀 전체가 똑같이 쓸 수 있어요.

쉬운 비유

같은 레시피북을 팀원 각자가 한 권씩 받아 두는 거예요.
책이 같으니까 "3번 레시피대로 해줘" 한마디면 서로 통해요.
각자 한 번만 깔면, 팀이 같은 말로 일하게 됩니다.

잠깐, 정리!

  • Step 0: Git · Node.js · Bun · Claude Code가 있는지 확인 (Claude Code는 로그인까지)
  • Step 1: 터미널에서 git clone 과 ./setup 두 줄로 설치
  • Step 2: ls ~/.claude/skills/gstack으로 등록됐는지 확인
  • Step 3: /office-hours로 설치 확인
  • Windows 사용자는 영문 경로를 추천해요.
  • 팀원도 Step 1의 두 줄을 자기 PC에서 한 번 돌리면 같은 스킬을 써요.
