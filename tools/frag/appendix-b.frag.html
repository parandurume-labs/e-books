CLAUDE.md

언제 쓰나. 볼트를 만든 첫날 루트에 놓습니다. AI가 이 폴더에서 일을 시작할 때 먼저 읽는 파일입니다. 어디서 나왔나. 11장입니다.

# 솔빛테크 위키 · AI 작업 규칙

## 1. 절대 규칙 (예외 없음)
1. 볼트에 없는 사실을 지어내지 않는다. 모르면 「확인 필요」라고 쓴다.
2. 근거 없는 수치를 쓰지 않는다. 숫자에는 근거 노트를 [[대괄호]]로 적는다.
3. 사람 이름·직함·회사명을 추측해 완성하지 않는다. 원문 표기를 쓴다.
4. 기존 노트와 모순되면 고치지 말고 「모순」으로 따로 보고한다.
5. 원문(회의록·메일·보고서)은 한 글자도 고치지 않는다. 오타도 그대로 둔다.
6. confidence: draft 인 노트와 confidential 이 「대외비」인 고객명·단가·인건비는
   대외 문서에 쓰지 않는다.

## 2. 쓰기 권한
- 새 파일을 만들어도 되는 곳은 _reports/ 와 _moc/ 두 곳이다.
- Sources/ 는 사람이 검토한 뒤에만 들어간다. 자동 작업은 「고칠 목록」만 남긴다.
- confidence: reviewed 인 노트와 파일 삭제·이동은 사람에게 요청한다.

## 3. 정본 필드명 (뜻이 같은 새 이름을 만들지 않는다)
- class, id, owner, start, due, updated, since, confidential
- status, stage, priority, blocked_by, confidence · 과제: period, funder, budget
- pdm_uses, pdm_output_of, pdm_owner, pdm_intent_of

## 4. 통제 어휘 (목록 밖의 값을 쓰지 않는다)
- 제품 status: 기획 / 개발 / 운영 / 중단
- 과제·기회 status: 기획 / 진행 / 검토 / 완료 / 보류
- confidence: draft / reviewed · priority: 상 / 중 / 하
- confidential: 공개 / 사내 / 대외비
애매하면 값을 비우고 본문에 「확인 필요」를 적는다.

## 5. 클래스와 ID (제목이 바뀌어도 id 는 그대로 둔다)
- PRD- 제품(판매·납품 단위) · CAP- 기술역량(재사용 가능한 기술 묶음)
- PRJ- 과제(계약·예산 있음) · OPP- 기회(없음) · ORG- 조직 · DEC- 결정

## 6. 틀리기 쉬운 사실 (여기 적힌 것이 정본이다)
- 창고봇은 제품(PRD-001), 객체인식은 기술역량(CAP-객체인식). 둘을 묶지 않는다.
- 픽뷰는 실증 데이터가 없고 대성물류는 계약 전이다. 실적으로 쓰지 않는다.
- 웨어트윈 TRL 은 노트에 4와 6이 함께 있다. 어느 쪽도 쓰지 말고 「확인 필요」로 둔다.
- 「이대표」와 「김대표」는 다른 표기다. 같은 사람으로 합치지 않는다.

## 7. 산출물
- 새 노트는 _ops/templates/ 의 템플릿을 쓴다. AI가 만든 노트에는
  confidence: draft 와 generated_by 를 넣는다. 리포트는 1000자 이내.

1절부터 5절까지는 어느 회사나 같고 6절만 회사마다 다릅니다. AI가 같은 실수를 두 번 하면 한 줄씩 늘리세요.

언제 쓰나. _ops/scripts/validate.py 로 저장해 매주 돌립니다. 필수 필드 누락, 통제 어휘 밖 상태값, 끊어진 링크, 오래된 노트, 금지 필드명 다섯 가지를 잡습니다. 어디서 나왔나. 17장이고 스케줄은 14장입니다.

# -*- coding: utf-8 -*-
"""볼트 점검. 표준 라이브러리만 씁니다.  python "_ops/scripts/validate.py"
결과는 _reports/점검-YYYY-MM-DD.md, 요약 한 줄은 _reports/validate-history.csv 에 쌓입니다."""
import datetime, re, sys
from collections import Counter
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]   # _ops/scripts/ 에서 두 단계 위가 볼트 루트
STALE = 30                                   # 이만큼 손대지 않은 노트를 방치로 봅니다
REQUIRED = {
    "제품": ["id", "status", "owner", "since", "updated"],
    "기술역량": ["id", "trl", "evidence", "updated"],
    "과제": ["id", "status", "owner", "period", "funder", "budget", "updated"],
    "기회": ["id", "status", "owner", "stage", "due", "updated"],
    "조직": ["id", "updated"], "결정": ["id", "date", "updated"],
    "업무로그": ["date", "owner", "updated"], "회의록": ["date", "updated"],
}
# 같은 status 인데 클래스마다 목록이 다릅니다. 제품은 넷, 과제와 기회는 다섯입니다.
WORK = ["기획", "진행", "검토", "완료", "보류"]
STATUS = {"제품": ["기획", "개발", "운영", "중단"], "과제": WORK, "기회": WORK}
# 금지 필드명. 나쁜 예로만 등장해야 하는 이름입니다.
# 어제는 due, 오늘은 deadline, 내일은 마감일로 적히면 아무것도 셀 수 없습니다.
FORBIDDEN = ["deadline", "마감일", "uses_tech", "tech_used", "사용기술"]
FM = re.compile(r"\A---\r?\n(.*?)\r?\n---", re.S)
KEY = re.compile(r"^([A-Za-z_][A-Za-z0-9_]*)\s*:\s*(.*)$")
LINK = re.compile(r"\[\[([^\]|#]+)")


def frontmatter(text):
    """--- 로 감싼 부분만 읽는 최소 파서입니다. 이 볼트가 쓰는 문법만 다룹니다."""
    head = FM.match(text)
    if not head:
        return None, ""
    meta, key = {}, None
    for line in head.group(1).splitlines():
        found = KEY.match(line)
        if found:
            key, value = found.groups()
            meta[key] = value.strip().strip('"').strip("'")
        elif line.strip() and key:                 # 여러 줄로 적은 목록의 항목
            meta[key] = (meta[key] + " " + line.strip().lstrip("-")).strip()
    return meta, head.group(1)


def main():
    src, out = ROOT / "Sources", ROOT / "_reports"
    if not src.is_dir():
        print("Sources 폴더를 찾지 못했습니다: " + str(src))
        return 1
    notes = sorted(src.rglob("*.md"))
    known = set(p.stem for p in ROOT.rglob("*.md"))
    today, found = datetime.date.today(), []

    def add(level, path, msg):
        found.append((level, path.relative_to(ROOT).as_posix(), msg))

    for path in notes:
        text = path.read_text(encoding="utf-8")
        meta, raw = frontmatter(text)
        if meta is None:
            add("ERROR", path, "frontmatter 가 없습니다")
            continue
        for name in FORBIDDEN:                                     # 금지 필드명
            if re.search(r"^\s*-?\s*" + re.escape(name) + r"\s*:", raw, re.M):
                add("ERROR", path, "금지 필드명 " + name + ". 마감은 언제나 due 입니다")
        cls = meta.get("class", "")
        if cls not in REQUIRED:
            add("ERROR", path, "설계서에 없는 class: " + (cls or "비어 있음"))
            continue
        for field in REQUIRED[cls]:                                # 필수 필드 누락
            if not meta.get(field):
                add("ERROR", path, "필수 필드 누락: " + field)
        status = meta.get("status", "")                            # 통제 어휘 밖 값
        if status and cls in STATUS and status not in STATUS[cls]:
            add("ERROR", path, "통제 어휘 밖 status: %s (%s 목록은 %s)"
                % (status, cls, " / ".join(STATUS[cls])))
        for target in set(t.strip() for t in LINK.findall(text)):  # 끊어진 링크
            if target and target not in known:
                add("ERROR", path, "끊어진 링크: [[" + target + "]]")
        try:                                                       # 오래된 노트
            updated = datetime.date.fromisoformat(meta.get("updated", ""))
        except ValueError:
            updated = datetime.date.fromtimestamp(path.stat().st_mtime)
        if (today - updated).days > STALE:
            add("WARN", path, "%d일 동안 갱신이 없습니다" % (today - updated).days)

    n, stamp = Counter(lv for lv, _, _ in found), today.isoformat()
    lines = ["# 볼트 점검 %s" % stamp, "",
             "노트 %d개 · ERROR %d건 · WARN %d건" % (len(notes), n["ERROR"], n["WARN"]), ""]
    lines += ["- **%s** `%s` %s" % row for row in sorted(found)] or ["규칙 위반 없음"]
    out.mkdir(exist_ok=True)
    (out / ("점검-%s.md" % stamp)).write_text("\n".join(lines) + "\n", encoding="utf-8")
    hist = out / "validate-history.csv"
    if not hist.exists():
        hist.write_text("date,notes,error,warn\n", encoding="utf-8")
    with hist.open("a", encoding="utf-8") as f:
        f.write("%s,%d,%d,%d\n" % (stamp, len(notes), n["ERROR"], n["WARN"]))
    print("노트 %d개 · ERROR %d · WARN %d" % (len(notes), n["ERROR"], n["WARN"]))
    return 1 if n["ERROR"] else 0


if __name__ == "__main__":
    sys.exit(main())

# ingest
## 순서
1. 원문을 Sources/40-Worklog/YYYY-MM-DD-제목.md 로 저장한다. 한 글자도 고치지 않는다.
2. 네 가지를 뽑는다.
   - 결정: 「~하기로 했다」에 해당하는 것. 대안과 이유를 함께 적는다
   - 액션: 담당자와 기한이 있는 것
   - 사실 변경: 기존 노트의 필드를 바꿔야 하는 것
   - 신규 개체: 아직 노트가 없는 조직·제품
3. 뽑은 것을 표로 보고한다. 파일은 아직 만들지 않는다.
4. 승인을 받으면 _ops/templates/ 의 템플릿으로 노트를 만든다.
## 규칙
- 원문에 없는 내용을 추론하지 않는다. 모호하면 「확인 필요」로 남긴다
- 「~같다」, 「~라고 함」처럼 불확실한 진술은 confidence: draft 로 표시한다
- 기존 노트와 모순되면 고치지 말고 「모순」으로 따로 보고한다
- 사람 이름은 원문 표기를 그대로 쓴다. 직함을 추측해 붙이지 않는다
- 계약 전 고객은 confidential: 대외비 로 표시한다
## 끝났는지 확인하는 법
모든 문장을 원문에서 찾을 수 있고 「확인 필요」가 한 건 이상 남아 있다.

# audit

대시보드 스크립트

언제 쓰나. _ops/scripts/dashboard.py 로 저장해 매주 월요일 아침에 돌립니다. 4번 예약 작업 대신 쓰는 판이고, AI 없이 돌아서 결과가 항상 같습니다. 어디서 나왔나. 15장입니다.

# -*- coding: utf-8 -*-
"""_moc/000-대시보드.md 를 다시 만듭니다.  python "_ops/scripts/dashboard.py"
Sources/ 는 읽기만 하고, 쓰는 곳은 _moc/ 한 곳입니다."""
import datetime, re, sys
from collections import Counter
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
SOON, STALE = 21, 30                         # 마감 임박 기준 · 방치 기준
FM = re.compile(r"\A---\r?\n(.*?)\r?\n---", re.S)
KEY = re.compile(r"^([A-Za-z_][A-Za-z0-9_]*)\s*:\s*(.+)$", re.M)


def day(value):
    try:
        return datetime.date.fromisoformat(value)
    except ValueError:
        return None


def main():
    src = ROOT / "Sources"
    if not src.is_dir():
        print("Sources 폴더를 찾지 못했습니다: " + str(src))
        return 1
    today, rows, ok = datetime.date.today(), [], 0
    for path in sorted(src.rglob("*.md")):
        head = FM.match(path.read_text(encoding="utf-8"))
        if not head:
            continue
        m = {k: v.strip().strip('"').strip("'") for k, v in KEY.findall(head.group(1))}
        ok += m.get("confidence") == "reviewed"
        rows.append(dict(name=path.stem, cls=m.get("class", ""), owner=m.get("owner", ""),
                         status=m.get("status", ""), start=day(m.get("start", "")),
                         due=day(m.get("due", "")), updated=day(m.get("updated", ""))))

    track = [r for r in rows if r["cls"] in ("과제", "기회")]
    dated = sorted([r for r in track if r["start"] and r["due"]], key=lambda r: r["due"])
    undated = [r for r in track if r not in dated]
    stale = [r for r in rows if r["updated"] and (today - r["updated"]).days > STALE]
    soon = [r for r in dated if r["status"] not in ("완료", "보류")
            and 0 <= (r["due"] - today).days <= SOON]
    counts = Counter(r["status"] for r in track if r["status"])

    out = ["# 대시보드", "", "> 자동 생성 · %s · 직접 고치면 다음 실행 때 사라집니다." % today, "",
           "| 지표 | 값 |", "|---|---|", "| 전체 노트 | %d |" % len(rows),
           "| 검증된 노트 | %d%% |" % (round(ok * 100 / len(rows)) if rows else 0),
           "| 마감 %d일 이내 | %d |" % (SOON, len(soon)),
           "| %d일 이상 갱신 없음 | %d |" % (STALE, len(stale)),
           "| 상태별 | %s |" % (" · ".join("%s %d" % kv for kv in counts.most_common())
                                or "기록 없음"), "",
           "```mermaid", "gantt", "    title 일정",
           "    dateFormat YYYY-MM-DD", "    axisFormat %m월"]
    seq = 0
    for section in ("과제", "기회"):
        picked = [r for r in dated if r["cls"] == section]
        if picked:
            out += ["", "    section " + section]
        for r in picked:
            seq += 1
            tag = {"완료": "done, ", "진행": "active, "}.get(r["status"], "")
            if r in soon:
                tag += "crit, "
            out.append("    %s :%st%d, %s, %s"
                       % (r["name"].replace(":", " "), tag, seq, r["start"], r["due"]))
    out += ["```", "", "## 이번 주에 볼 것", ""]
    out += ["- [[%s]] · D-%d · %s" % (r["name"], (r["due"] - today).days,
            r["owner"] or "담당 미기재") for r in soon] or ["- 마감 임박 항목 없음"]
    out += ["", "## 일정 미기재", ""]
    out += ["- [[%s]] · start 나 due 가 비어 간트에 나오지 않습니다" % r["name"]
            for r in undated] or ["- 없음"]

    (ROOT / "_moc").mkdir(exist_ok=True)
    (ROOT / "_moc" / "000-대시보드.md").write_text("\n".join(out) + "\n", encoding="utf-8")
    print("노트 %d개 · 마감 임박 %d건 · 방치 %d건" % (len(rows), len(soon), len(stale)))
    return 0


if __name__ == "__main__":
    sys.exit(main())
