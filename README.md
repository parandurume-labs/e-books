## 디자인 시스템

4권 모두 `assets/` 의 공용 CSS·JS를 씁니다. 새 책을 만들 때는 스타일을 복사하지 말고
[`assets/README.md`](assets/README.md) 를 보고 강조색 4개만 정의하세요.

각 책은 좌측 목차 상주, 다크 모드(설정 유지), 읽기 진행바, 「이 장에서」 자동 목차, `⌘K` 검색을 지원합니다.
