CHAPTER 8

첫 번째 스킬: "인사하기"

Hello World! 드디어 직접 만드는 시간입니다

지금부터는 만드는 사람(Maker)입니다

여기까지 오신 분들, 진심으로 축하드려요.

1부에서 AI가 뭔지 배웠고, 2부에서 스킬 패키지의 구조를 해부했죠. 재미있었지만, 솔직히 말하면 지금까지는 "구경"이었어요. 다른 사람이 만든 걸 들여다본 거예요.

이제 달라집니다.

지금부터는 구경하는 사람이 아니라 만드는 사람이에요. 코드를 읽는 사람이 아니라 코드를 쓰는 사람. 스킬을 쓰는 사람이 아니라 스킬을 만드는 사람.

긴장되시나요? 괜찮아요. 프로그래밍의 오랜 전통이 하나 있거든요.

모든 것은 "Hello, World!"에서 시작한다는 것.

1972년 브라이언 커니핸이 B 언어 교재에 "Hello, World!"를 화면에 출력하는 예제를 처음 넣었고, 1978년 데니스 리치와 함께 쓴 C 언어 교재로 이어지며 전통이 됐어요. 그 뒤 50년 넘게, 새로운 기술을 배울 때는 항상 가장 간단한 것부터 만들어보는 관례가 이어지고 있죠.

우리도 그 전통을 따릅니다. 가장 간단하고, 가장 쉽고, 가장 빨리 결과를 볼 수 있는 스킬부터 만들어볼 거예요.

이름하여: "인사하기" 스킬.

뭘 만들 거예요?

우리가 만들 스킬은 이거예요:

인사하기 스킬

사용자가 "안녕"이라고 말하면, AI가 따뜻한 한국어 인사와 함께 오늘에 대한 재미있는 사실을 알려주는 스킬.

단순하죠? 바로 그게 포인트예요.

첫 번째 스킬은 단순해야 해요. 복잡하면 중간에 막히고, 막히면 재미없고, 재미없으면 포기하니까. 일단 성공의 맛을 봐야 다음으로 갈 수 있어요.

자, 시작합시다. 딱 3단계면 됩니다.

Step 1: 폴더 만들기

모든 스킬은 폴더 하나에서 시작해요. 스킬의 집을 짓는 거라고 생각하면 돼요.

터미널(명령어 창)을 열고, 다음 명령어를 입력하세요:

mkdir hello-skill
cd hello-skill

끝이에요. 정말로요. 폴더 하나 만들고 들어간 게 전부예요.

"이게 다예요?" 네, 이게 다예요. 스킬 패키지는 기본적으로 폴더 안에 파일을 넣는 것이거든요. 대단한 설치 과정이나 복잡한 설정 같은 거 없어요.

터미널이 뭔지 모르겠다면? (챕터 1에서 약속한 설명이에요)

터미널은 컴퓨터와 글자로 대화하는 창이에요. 마우스로 폴더를 더블클릭하는 대신, 하고 싶은 일을 문장으로 적어서 Enter를 누르는 방식이죠. 검은 화면에 글자만 있어서 무섭게 생겼지만, 하는 일은 탐색기와 똑같아요.

여는 법. Windows는 시작 메뉴에서 "PowerShell"을 검색해서 열고, Mac은 Command+스페이스를 눌러 "터미널"을 검색해서 열면 돼요.

쓰는 법. 명령어 한 줄을 치고 Enter. 그게 전부예요. mkdir hello-skill은 "hello-skill이라는 폴더를 만들어라", cd hello-skill은 "그 폴더 안으로 들어가라"는 뜻이에요. cd ..는 반대로 한 칸 위로 나오라는 뜻이고요.

지금 어느 폴더에 있는지 모르겠다면, Windows는 cd, Mac은 pwd를 치면 현재 위치가 나와요.

지금 우리 폴더 구조는 이렇게 생겼어요:

hello-skill/
  (아직 비어 있음)

텅 빈 집이죠. 이제 여기에 가장 중요한 파일을 넣을 거예요.

Step 2: SKILL.md 작성하기

자, 이제 스킬의 심장을 만들 차례예요. SKILL.md 파일이요.

2부에서 배웠죠? SKILL.md는 AI에게 주는 레시피 카드라고요. 이 파일 하나가 스킬의 전부예요.

파일은 메모장이나 VS Code 같은 텍스트 편집기를 열어서 만들어요. 윈도우 메모장을 쓴다면 저장할 때 "파일 형식"을 "모든 파일"로 바꿔야 .txt가 안 붙어요.

가장 흔한 실패: SKILL.md.txt

메모장은 기본 설정에서 파일 이름 뒤에 .txt를 몰래 붙여요. 그러면 파일 이름이 SKILL.md.txt가 되고, 스킬은 영영 인식되지 않아요. 저장 창에서 "파일 형식"을 "모든 파일(*.*)"로 바꾸고, 이름은 따옴표로 감싸서 "SKILL.md"라고 적으면 확실해요. 저장한 뒤 탐색기에서 파일 이름이 정확히 SKILL.md인지 눈으로 한 번 확인하세요.

hello-skill 폴더 안에 SKILL.md 파일을 만들고, 다음 내용을 그대로 입력하세요:

---
name: hello-skill
description: "사용자에게 따뜻한 한국어 인사를 해주는 스킬"
---

# 인사하기 스킬

당신은 따뜻하고 친근한 한국어 인사 전문가입니다.

사용자가 인사를 하면 (예: "안녕", "하이", "hello", "좋은 아침") 다음을 수행하세요:

1. 시간대에 맞는 따뜻한 한국어 인사로 응답하세요
   - 아침이면 "좋은 아침이에요! ☀️"
   - 낮이면 "안녕하세요! 좋은 하루 보내고 계신가요? 😊"
   - 저녁이면 "좋은 저녁이에요! 오늘 하루 수고 많으셨어요 🌙"
2. 오늘 날짜에 대한 재미있는 사실을 하나 알려주세요
   - 역사적 사건, 유명인 생일, 특별한 기념일 등
3. 하루를 응원하는 짧은 한마디를 덧붙이세요

## 톤과 스타일
- 친구처럼 편하지만 예의 바르게
- 이모지를 적절히 사용
- 너무 길지 않게, 3-5줄 정도로

## 예시 응답
"좋은 아침이에요! ☀️

오늘은 3월 27일인데요, 1845년에 X선을 발견한 뢴트겐이 태어난 날이에요!
눈에 보이지 않는 것도 발견할 수 있다니, 오늘 하루도 새로운 발견이
있는 멋진 날이 되길 바랄게요! 💪"

다 입력하셨나요? 그러면 저장하세요.

지금 폴더 구조:

hello-skill/
  └── SKILL.md    ← 이게 전부!

잠깐, 이 파일을 해부해볼까요?

방금 만든 파일이 뭘 하는 건지 하나하나 뜯어볼게요.

1. 프론트매터 (맨 위 --- 사이 부분)

---
name: hello-skill
description: "사용자에게 따뜻한 한국어 인사를 해주는 스킬"
---

이건 스킬의 "명찰"이에요. Claude Code가 "이 스킬이 뭘 하는 거지?"를 빠르게 파악하는 데 사용해요.

name은 스킬을 부르는 이름이에요. 6장에서 배운 대로 케밥 케이스로 씁니다. 이게 없으면 스킬이 제대로 등록되지 않으니 꼭 넣으세요.

description은 스킬의 자기소개예요. 사용자가 인사를 하면, Claude Code가 이 description을 보고 "아, 인사하기 스킬을 쓰면 되겠다!"라고 판단하는 거예요.

2. 제목과 역할 (# 인사하기 스킬)

# 인사하기 스킬

당신은 따뜻하고 친근한 한국어 인사 전문가입니다.

AI에게 "너는 이런 사람이야"라고 역할을 부여하는 부분이에요. 배우에게 "너는 인사 전문가야"라고 대본을 주는 것과 같아요.

3. 지시사항 (번호 목록)

"이런 순서로 이렇게 해"라는 구체적인 지시예요. 요리 레시피의 조리 순서와 같죠.

4. 톤과 스타일

"어떤 느낌으로 해"라는 스타일 가이드예요. "친구처럼 편하지만 예의 바르게", 이 한 줄이 AI의 응답 분위기를 결정해요.

5. 예시 응답

"이런 식으로 해줘"라는 샘플이에요. AI는 예시를 보면 훨씬 더 정확하게 의도를 파악해요.

놀라운 사실

방금 한 건 프로그래밍이 아니에요. 한국어로 글을 쓴 거예요. "이렇게 인사해줘"를 체계적으로 정리한 것뿐이에요. 그런데 이게 AI를 움직이는 스킬이 됩니다. 이게 2020년대의 마법이에요.

잠깐, 준비물부터 챙길게요

지금까지는 폴더 하나와 텍스트 파일 하나만 있으면 됐어요. 그런데 다음 단계에서는 Claude Code가 실제로 필요해요. 아직 설치를 안 했다면 여기서 같이 해요.

1. Claude Code 설치하기

Claude Code는 터미널에서 실행하는 프로그램이에요. 설치는 명령어 한 줄이에요:

npm install -g @anthropic-ai/claude-code

여기 나오는 npm은 Node.js를 설치하면 같이 딸려오는 프로그램이에요. "npm이 뭔지 모르겠다" 또는 "명령어를 찾을 수 없다"는 메시지가 나오면, nodejs.org에서 Node.js를 먼저 설치하고 터미널을 새로 연 다음 위 명령어를 다시 실행하세요.

-g는 "global(전역)"이라는 뜻이에요. 특정 폴더가 아니라 컴퓨터 어디서든 쓸 수 있게 설치한다는 표시죠.

2. 설치가 됐는지 확인하기

claude --version

숫자로 된 버전이 나오면 성공이에요. "그런 명령어 없음" 같은 메시지가 나오면 설치가 안 된 거니까, 터미널을 완전히 닫았다가 새로 열고 다시 확인해보세요.

3. 첫 실행과 로그인

터미널에 claude라고 치면 Claude Code가 시작돼요. 처음 실행하면 브라우저 창이 열리면서 Anthropic 계정 로그인을 요구해요. 로그인하고 나면 터미널로 돌아와서 계속 진행하면 돼요.

돈이 드나요? 네, 들어요

Claude Code를 쓰려면 유료 플랜이나 API 크레딧이 필요해요 (2026년 7월 기준). 프로그램 설치 자체는 무료지만, 로그인한 계정에 사용할 수 있는 요금제나 크레딧이 없으면 대화가 시작되지 않아요. 최신 요금제는 claude.com에서 확인하세요.

여기까지 됐으면 준비 끝이에요. 이제 마지막 단계로 갑시다.

Step 3: 설치하고 테스트하기

스킬을 만들었으니, 이제 Claude Code에게 알려줘야 해요. "이런 스킬이 있으니 써봐!"라고요.

설치 방법

방법은 아주 간단해요. 우리가 만든 hello-skill 폴더를 Claude Code의 스킬 폴더에 넣으면 됩니다.

그 전에 하나. Step 1에서 cd hello-skill로 폴더 안에 들어가 있으니까, 먼저 한 칸 위로 나와야 해요. 이걸 빼먹으면 "그런 파일이나 디렉토리가 없습니다"라는 에러가 나요.

cd ..

방법 A: 글로벌 스킬로 설치 (추천)

어디서 Claude Code를 켜든 쓸 수 있게, 홈 디렉토리의 스킬 폴더에 넣는 방법이에요. 처음 만드는 스킬은 이쪽이 편해요:

mkdir ~/.claude
mkdir ~/.claude/skills
cp -r hello-skill ~/.claude/skills/

~는 "내 홈 폴더"라는 뜻이에요. Mac이면 /Users/내이름/, Windows면 C:\Users\내이름\이죠. 앞의 두 줄에서 "이미 있습니다" 같은 메시지가 나와도 괜찮아요. 폴더가 이미 있다는 뜻일 뿐이니 다음 줄로 넘어가면 돼요.

방법 B: 프로젝트 스킬로 설치

이미 다루고 있는 프로젝트 폴더가 있다면, 그 폴더 안에 .claude/skills/를 만들어서 넣는 방법도 있어요. 이렇게 하면 그 프로젝트에서 Claude Code를 실행할 때만 스킬이 보여요:

# 프로젝트 폴더에서 실행
mkdir .claude
mkdir .claude/skills
cp -r hello-skill .claude/skills/

명령어가 자꾸 에러가 나면, 마우스로 하세요

명령어 대신 탐색기(Windows)나 Finder(Mac)로 hello-skill 폴더를 .claude/skills/ 안에 끌어다 놓아도 똑같아요. 결과만 같으면 되니까요. 운영체제마다 명령어 문법이 조금씩 달라서(특히 PowerShell은 Mac/Linux 명령어를 그대로 받지 않아요) 마우스로 옮기는 쪽이 오히려 확실할 때가 많아요.

폴더 이름 앞에 점이 붙은 .claude는 숨김 폴더라 안 보일 수 있어요. Windows 탐색기는 "보기 → 숨긴 항목"을 켜고, Mac Finder는 Command+Shift+.를 누르면 보여요. 주소창에 %USERPROFILE%(Windows) 또는 ~(Mac)를 입력하면 홈 폴더로 바로 갈 수 있어요.

테스트!

설치했으면, 이제 Claude Code를 실행하고 인사해보세요:

claude

Claude Code가 실행되면, 간단하게 이렇게 말해보세요:

안녕!

그러면... 두근두근...

"안녕하세요! 좋은 하루 보내고 계신가요? 😊

오늘은 3월 27일인데요, 1886년에 아파치 족의 전설적인 지도자 제로니모가 항복한 날이래요. 포기하지 않는 정신은 정말 대단하죠!

오늘 하루도 포기하지 않고 멋지게 보내세요! 💪"

작동합니다!

방금 만든 스킬이, AI의 응답 방식을 바꿨어요. 그냥 "안녕하세요"라고만 대답하던 AI가, 재미있는 사실과 응원 메시지까지 전해주는 친구가 됐어요.

축하합니다! 방금 첫 번째 AI 스킬을 만든 거예요!

뒤에서 무슨 일이 일어난 걸까?

"그래, 작동은 하는데... 도대체 어떻게 되는 거야?"

좋은 질문이에요. "안녕!"이라고 입력한 순간부터 응답이 나올 때까지, 뒤에서 일어나는 일을 순서대로 볼게요:

  1. 사용자 입력: "안녕!"이라고 타이핑
  2. 스킬 탐색: Claude Code가 설치된 스킬들의 description을 훑어봄
  3. 매칭: "사용자에게 따뜻한 한국어 인사를 해주는 스킬". 오, 이게 딱이네!
  4. 스킬 로드: SKILL.md의 내용을 읽어서 AI의 지시사항에 추가
  5. 응답 생성: AI가 스킬의 지시를 따라 인사 + 재미있는 사실 + 응원 메시지를 생성
  6. 출력: 완성된 응답이 화면에 표시!

핵심은 3번과 4번이에요. Claude Code가 자동으로 적절한 스킬을 찾아서 적용하는 거예요. 스킬 이름을 직접 부르지 않아도, AI가 문맥을 보고 "아, 이 상황에서는 이 스킬이 맞겠다"고 판단하는 거죠.

이름을 직접 불러 쓸 수도 있어요

자동으로 골라주는 게 기본이지만, "지금 이 스킬을 써"라고 못 박고 싶을 때가 있죠. 그럴 때는 스킬 이름을 그대로 말하면 돼요.

hello-skill 스킬로 인사해줘

슬래시를 붙여 /hello-skill이라고 입력하는 방법도 있어요. 챕터 2에서 "/review 한 단어가 긴 프롬프트를 대신한다"고 했던 게 바로 이 모습이에요.

둘의 차이는 이래요. description이 잘 쓰여 있으면 안 불러도 알아서 나오고, 이름을 직접 부르면 확실하게 그 스킬만 나와요. 처음에는 이름을 직접 불러서 "제대로 설치됐는지" 확인하고, 그 다음에 자동으로 나오는지 시험해보는 순서가 편해요.

레스토랑 비유로 다시 보면

나 = 손님 ("안녕!")
Claude Code = 웨이터 (어떤 레시피를 쓸지 판단)
SKILL.md = 레시피 (인사 전문가처럼 응답하라)
AI = 셰프 (레시피대로 응답 만들기)
응답 = 완성된 요리 (따뜻한 인사 + 재미있는 사실)

변형 도전! 나만의 색깔 입히기

첫 스킬이 작동하는 걸 확인했으니, 이제 조금씩 바꿔볼 차례예요. 스킬의 매력은 내 마음대로 고칠 수 있다는 거예요.

변형 1: 사투리 인사 스킬

SKILL.md의 톤 부분을 이렇게 바꿔보세요:

## 톤과 스타일
- 부산 사투리로 인사하기
- 구수하고 정겨운 느낌
- "~하이가", "~아이가" 같은 부산 특유의 어미 사용

그러면 AI가 이렇게 응답해요: "오, 왔나! 좋은 아침이다 아이가! ☀️"

변형 2: 격식체 인사 스킬

## 톤과 스타일
- 조선시대 선비처럼 격식 있게
- "~하옵니다", "~이로소이다" 같은 고풍스러운 어미
- 한자 성어를 하나 포함

변형 3: 랩퍼 인사 스킬

## 톤과 스타일
- 힙합 스타일로 인사하기
- 라임을 넣어서 리듬감 있게
- "yo!", "check it" 같은 표현 자연스럽게 섞기

어때요? 톤 부분 몇 줄만 바꿨는데, 완전히 다른 스킬이 되죠?

이게 바로 스킬의 힘이에요. 한국어로 글을 바꾸면, AI의 행동이 바뀌어요. 코드를 짤 줄 몰라도, 글을 쓸 줄 알면 AI를 원하는 대로 움직일 수 있어요.

혹시 안 되나요? 당황하지 마세요

처음 만들 때 안 되는 건 당연해요. 몇 가지 흔한 문제와 해결법을 알려드릴게요.

"스킬이 인식이 안 돼요"

  • 파일 이름이 정확히 SKILL.md인지 확인 (대문자!). 메모장으로 저장했다면 SKILL.md.txt가 됐을 확률이 높아요
  • Step 3에서 cd ..를 했는지 확인. 폴더 안에 들어간 채로 복사하면 "그런 파일 없음" 에러가 나요
  • 파일이 hello-skill/SKILL.md 경로에 있는지 확인
  • Claude Code를 재시작해보세요

"스킬이 적용되는 것 같지 않아요"

  • name 필드가 있는지 확인. 이게 빠지면 스킬이 등록조차 안 돼요
  • description 필드가 있는지 확인. 이게 없으면 Claude Code가 스킬을 찾지 못해요
  • 프론트매터의 ---가 정확히 두 줄 있는지 확인

"응답이 내 기대와 좀 달라요"

  • 이건 정상이에요! AI는 매번 조금씩 다르게 응답해요
  • 더 정확한 응답을 원하면, 지시사항을 더 구체적으로 적으면 돼요 (이건 다음 챕터에서!)

잠깐, 정리!

  • AI 스킬 만들기는 딱 3단계: 폴더 만들기 → SKILL.md 작성 → 설치/테스트
  • 준비물은 Claude Code 하나예요. npm install -g @anthropic-ai/claude-code로 설치하고, claude --version으로 확인해요
  • 메모장으로 저장할 때는 "파일 형식"을 "모든 파일"로. 안 그러면 SKILL.md.txt가 돼서 스킬이 인식되지 않아요
  • 명령어가 어려우면 탐색기나 Finder로 폴더를 끌어다 놓아도 결과는 같아요
  • SKILL.md는 프론트매터(name, description)와 본문(지시사항)으로 구성돼요
  • 스킬의 본문은 한국어로 쓰는 지시문이에요. 코딩이 아니에요!
  • 톤과 스타일 부분만 바꿔도 완전히 다른 성격의 스킬이 돼요
  • 안 되면 당황하지 말고, 파일명과 경로를 차근차근 확인하세요
